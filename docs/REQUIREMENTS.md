# DeskNodes Windows 需求与功能

本文件是 Windows 产品目标，不是已实现说明。来源、版本与文档分工见 [入口](README.md)，裁决及平台限制见 [可行性](FEASIBILITY.md)。最低目标为 Windows 11 22H2（build 22621），不承诺 Windows 10 支持。

## 范围与术语

个人本地中文桌面待办便签；便签是长期容器，事项支持完成或划掉（不做了），两者互斥。业务日按当前时区与跨天时间计算，结束后形成只读快照。自由布局、停靠、单张折叠、全局收起、工具条收缩、临时浮起分别建模。

不含账号、云同步、提醒、截止时间、Markdown 富文本、跨便签拖动事项、历史编辑、隐私锁、屏幕共享自动隐藏、永久删除管理、旧 Tauri 自动迁移或发行签名交付。Windows 版不宣称直接兼容 Mac SQLite／JSON，详见 [备份](TECHNICAL_DESIGN.md#backup)。

<a id="fr-01"></a>
## FR-01 启动、空状态与托盘

启动读取本机库、执行支持的迁移、恢复展示偏好并检查跨天；空库不创建示例，保留工具条，仅新建与设置可用。工具条启动完整展开并重新计闲置时间，便签恢复上次全局收起目标。

macOS 菜单栏入口改为 Windows 通知区域（托盘）：依次新建便签、显示工具条、浮起／放回、选择便签…、历史记录…、最近删除…、设置…、退出；无便签时选择禁用。显示工具条只校正到已连接屏幕并展开工具条，不展开便签。系统可以把托盘图标放入折叠菜单，不能保证始终外露。

应用常驻托盘，便签和工具条不单独占任务栏／Alt+Tab；设置、历史用普通窗口，可在任务栏切换。没有 macOS Dock／全局应用菜单语义。关闭辅助窗口不退出；退出前提交编辑，组词未结束或保存失败则取消主动退出。系统强制结束／关机不可保证被阻止，见错误边界。

<a id="fr-02"></a>
## FR-02 新建与配色

工具条、托盘、应用内 Ctrl+N 和全局新建热键走同一流程。组词期间拒绝新建；先退出多选，收起时先展开，再创建无标题、一个空事项的自由便签。默认保存层级为“靠后（桌面近似）”，不承诺 Mac 桌面专用层；尝试激活并聚焦首行，激活被系统拒绝时提示用户点击便签。

默认和可选尺寸见 [UI](UI_SPEC.md#geometry)。未设置高度采用固定默认值，显式随内容继续保留；设置只影响以后新建。优先工具条屏幕，避开工具条完整目标和已显示便签，放不下级联并允许重叠。用当前未删除便签最少使用的颜色，并列从最近创建颜色之后循环；最近创建候选包含保留的已删除便签。

<a id="fr-03"></a>
## FR-03 标题、事项与输入

标题可空，显示“标题”；折叠摘要优先标题，否则第一条事项。事项支持新增、编辑、完成／取消、划掉／取消、删除、同便签排序；完成和划掉互斥，切换一方清除另一方，不立即归档或改排序；进度分母不含划掉。

采用系统文字输入链、选区和独立文字撤销。行尾悬停显示划掉、删除、排序手柄；键盘聚焦也可访问。Return 在当前项后新建并聚焦，组词中的 Return 仅交给 IME；Backspace 仅在空字符串行删除该行，Delete 在普通编辑中仍为原生向前删除。无选区且在首／末视觉行时 ↑／↓ 切相邻事项，多行内部先移光标。Ctrl+Return 切完成，Ctrl+Shift+X 切划掉。

多行粘贴过滤空行、移除常见列表前缀后拆项，首行插入选区、后续行依次新增；复选框前缀不设置完成。单行粘贴保留原生行为。

停顿约 0.4 秒保存；失焦、导出、跨天、退出提交有效编辑。普通刷新不得覆盖活跃或组词文字，未完成组词不写库。失焦清理多余空白事项，保留一条可输入行，不弹删除提示、不进入最近删除。候选窗、第三方 IME 与窗口切换均需 Windows 真机验证。

<a id="fr-04"></a>
## FR-04 选择、删除、撤销与最近删除

点击便签建立当前选择，和文字焦点分开；工具条不清选择。整张删除只在便签菜单，事项删除在行尾，工具条没有删除按钮。结构操作先安全提交；组词期间拒绝破坏输入上下文的动作。普通删除不确认，软删除，最后一张删除后保留工具条。

删除后严格 `0 ≤ elapsed < 5` 秒可撤销，恢复原 ID、内容、记录状态。多次从最新有效操作逐次撤销，批量为一项、一次恢复整批。Ctrl+Z 在删除有效且尚未新输入时优先撤销删除；新输入后回文字撤销，提示按钮在剩余时间内仍可用。队列不跨重启，成功导入清空；提示计操作条目数而非批次便签数。

托盘最近删除／历史顶部分段进入，显示最近 `30 × 86400` 秒内删除的便签和非空事项，打开、重新聚焦、恢复时刷新。整张恢复展开桌面便签，恢复同一删除时刻的未归档子项并校正屏幕；不带回更早单独删除项。单项恢复到仍存在原便签末尾。恢复移除对应撤销成员，批次其余成员保留。归档项不重激活、历史不修改。30 天仅限制列表，不增加底层恢复期限校验；不做物理清理或永久删除。

<a id="fr-05"></a>
## FR-05 自由布局、折叠与停靠

标题非编辑区域拖动，跟手移动，释放保存屏幕及位置；正文仍可输入。手动缩放关闭自动高度，菜单可恢复随内容。单张折叠保持顶部位置，展开恢复保存尺寸，不影响其他便签。

单张菜单停靠到当前屏幕顶部／左／右，当前边勾选；取消停靠仅已停靠时出现，恢复停靠前自由位置。自由便签靠边不自动停靠。同边排序、拖出、溢出标签和分页；拖出须越过保留带，点溢出标签提升显示。没有整体搬移停靠条入口。

布局基于每屏工作区，避开任务栏和其他已注册 AppBar；不自行注册 AppBar 占据其他应用空间。屏幕离线回退主屏并校正，工具条移动不带走自由便签。菜单顺序：颜色、三层级、停靠及条件取消停靠、折叠／展开、随内容、添加事项、选择多张、删除。Mac 旧停靠字段不作为 Windows 新字段；未来迁移须显式转换。

<a id="fr-06"></a>
## FR-06 整理与分页

主动整理时每屏按持久化顺序依次放入占用高度最小列，同高取最左，最短列也放不下则新页。宽、间距、留白见 UI。自动高度按整理宽重算，手动高度保持并受工作区限高；折叠按标题条占位并保留展开尺寸。停靠参与后转自由，内容、颜色、层级和历史不变。

新建、整理、停靠均避让工具条完整展开目标，即使当前圆形；工具条以后可覆盖手摆便签。整理为一次性，不持续吸回网格。保存布局和分页，当前页归零；多屏共用页码，页少屏停最后一页。非当前页隐藏，新建不属旧分页映射、默认可见；收起时整理按新布局展开。

<a id="fr-07"></a>
## FR-07 全局收起与展开

工具条／叠放提示控制整组便签。先提交有效编辑，真实窗口汇聚至工具条旁后隐藏，保留位置、尺寸、单张折叠与层级；展开仅恢复当前整理页，不重排。完整工具条显示叠放提示；圆形隐藏提示，仅收起且有便签显示数量角标，超过 99 为“99+”。收起结束浮起，无便签清除收起目标和空叠放。

只保存目标、不保存过渡；快速反向以最后请求为准。新建、整理、浮起的收起行为见各 FR。

<a id="fr-08"></a>
## FR-08 工具条方向、磁吸、收缩与边缘唤起

五动作固定新建、浮起／放回、整理、收起／展开、设置；默认竖向自由放置，设置可切横向。常规动作不抢文字焦点，新建和辅助窗口按流程激活。

完整从手柄、圆形从入口拖动，最大轴位移达到 4 DIP 视为拖动，抑制释放点击；优先指针所在屏，否则最后有效屏。只吸附可容纳完整目标的屏幕外边，距离外框 ≤81 DIP 取最近边，同距优先原边，否则左、右、上、下；相接屏内部边不吸。预览完整目标、释放吸附，不改变方向。圆形保留手柄端锚点，沿边按比例恢复；展开朝屏内、必要时沿边平移，保持入口被覆盖；自由位置按中心校正完整框。

自动收缩关闭／10／15／30 秒，默认 15；仅吸边且稳定展开、指针离开、无拖动／按住／动画、设置不可见、辅助技术模式未启用时计时。自由工具条不自动移边或收缩。操作、唤醒或条件中断重计完整时长。圆形悬停 140ms、单击或辅助激活展开；外部拖放经过不展开。只悬停唤起、未点击／滚动移出用 1.5 秒宽限；操作后恢复完整时长。收缩中移入可反向，展开中移出先完成；仅稳定态执行按钮。关闭自动收缩立即展开；圆形切方向保持圆形。

Windows 圆形入口仅在未被其他窗口遮挡且能收到指针消息时可边缘唤起，不是全局屏幕边缘监听。独占全屏、锁屏、UAC 安全桌面不可保证显示或唤出；边框全屏也需验证。提供托盘与全局热键作为替代，不以钩子、输入注入或未公开 Shell 技巧绕过。

<a id="fr-09"></a>
## FR-09 层级与浮起

逐便签保存“靠后（桌面近似）／普通／置顶”。靠后在非活动时请求 Z 序底部，不能保证图标之上且普通应用之下；不等同 macOS desktopIconWindow+1。编辑时可提升，离开后请求恢复。普通遵循 Windows Z 序，置顶为非系统窗口 topmost；不提供全局永久置顶开关，Windows 新库不虚构 Mac 旧偏好升级提示。

浮起由工具条、托盘、热键触发，收起先展开，原位置临时提升同批真实便签并尝试激活当前选择。再次触发、便签 Esc、切到其他应用、收起或清空结束；IME、热键录制、警告和文件对话框先处理自己的 Esc。内容、几何和保存层级不变，状态不跨重启。

不保证跨所有虚拟桌面，也不保证覆盖全屏或系统高优先级窗口；设置、历史、普通提示不临时置顶。系统拒绝激活时 Esc／离开检测可能不可用，可用按钮、托盘、热键放回。不使用全局键鼠钩子、不申请 UIAccess 或管理员权限。虚拟桌面由系统管理，不强制切换；跨桌面找回方案见可行性。

<a id="fr-10"></a>
## FR-10 跨天、归档与自动备份

默认 04:00，可设 00:00–23:59，当前时区和公历业务日；夏令时缺失时刻取下一个有效时刻，重复取第一次。启动、约 30 秒、唤醒、时钟／时区改变、设置更新检查，不保证秒级。

初次检查点不造昨日记录。向前只封存上个已观察业务日，未完成顺延到当前，完成与划掉归档退出实时清单，划掉不顺延。久未运行不补中间日。每天最多一份，不更新／删除／封存后补插成员；回拨不反向归档覆盖。组词延迟并在完成后重试。有效编辑、封存、归档、待记录删除清理与检查点同一事务。每次成功推进尝试自动 SQLite 副本，失败仅日志，副本规则见技术设计。

<a id="fr-11"></a>
## FR-11 历史

托盘进入，顶部分日历／最近删除。周一开始、可翻月、选日看冻结便签和事项，含删除与顺延目标。日／月完成率为冻结 completed 次数除以事项次数，含已删除、不含划掉；跨日重复出现按次数计，不去重、不平均每日百分比；无分母为“—”。只读，无快照显示“当天没有历史记录”，不捕获实时清单。最近删除恢复为 FR-04 独立写操作。

<a id="fr-12"></a>
## FR-12 设置、快捷键、登录启动

设置顺序通用、外观、工具条、新建便签、快捷键、数据，底部退出；一般即改即生效，无总保存按钮。Windows 快捷键映射见 [交互表](INTERACTION.md#keys)。全局默认 Ctrl+Alt+N／Ctrl+Alt+F，浮起可清除；AltGr 键盘可能冲突，允许改为 Ctrl+Shift 组合并提示风险。

录制支持 Ctrl／Alt／Shift 与字母、数字、Space，至少含 Ctrl，禁止 Windows 键及系统保留组合，不照搬 Mac ANSI 物理键码、禁用列表或 Command 语义。以 Windows 虚拟键注册；Esc 取消，两键不能相同；冲突保留旧值和绑定。注册热键不等于全局键盘监听。

首次登录启动询问“暂不启用／启用”，拒绝不再问。只有明确同意或设置动作才写系统启动项；默认普通非打包安装采用当前用户 Run 项，不需管理员。显示注册配置与错误，不声称知道任务管理器最终允许状态或已成功登录启动。打包替代方案有 DisabledByUser 等状态，不能照搬 Mac pendingApproval。导入意愿不自动操作系统。

<a id="fr-13"></a>
## FR-13 本地数据、导入导出

本地保存，无加密声明。导出：完成输入→提交→事务读取完整业务数据→系统保存对话框→原子写 JSON；取消不写文件，已提交编辑保留。

导入：系统选择 JSON→版本、引用、staging 校验→确认“替换全部本机数据？”→尝试候选新建热键→原子替换业务库→重建编辑上下文。无效、取消、组词、候选新建键冲突保留旧库；成功后浮起键若被占，仅提示、不回滚数据。成功结束多选／浮起、清旧结构及文字撤销、替换业务布局；本机展示偏好和系统启动项不替换。导入不立即跨天，后续正常调度处理旧检查点。

Windows 备份格式须另行定义和冻结后才能实现；当前不承诺 Mac JSON 或 SQLite 直接导入。详见技术设计的兼容门槛，不猜 Swift Codable 载荷。

<a id="fr-14"></a>
## FR-14 字号

设置四档及实时示例，全便签统一，Ctrl++／Ctrl+= 放大、Ctrl+- 缩小、Ctrl+0 标准，到端点不变。字号、行高、圆圈、展开标题和底部一起适配，宽和内边距固定；自动高度重算、固定内部滚动、停靠重排。工具条／设置／历史文字不受此档位影响。组词拒绝并回显实际档位，本机持久化、不入 JSON、不做单张字号。系统 DPI／辅助文本缩放仍须独立处理。

<a id="fr-15"></a>
## FR-15 多选与批量删除

Ctrl+单击便签进入并选中，Ctrl 从便签按住拖动可同手势框选；正文 Ctrl+单击仅在本产品命中规则下进入模式，须验证不损坏文字选择。菜单“选择多张…”预选本张，托盘“选择便签…”不预选。模式内点击切勾选、从便签或覆盖层拖矩形相交；普通框替换、Ctrl 框追加；空白点击清选择不退出。Ctrl+A 全选当前可见，Backspace／Delete 删所选，Esc／完成退出；空选择删除禁用，删除后退出、不确认，批次撤销见 FR-04。

进入前检查组词，收起先展开；真实便签临时提升，每屏临时覆盖层接收空白拖动，正文不可编辑。多选反馈和普通选择分开。仅当前虚拟桌面实际可见、当前整理页和已显示停靠便签可选；隐藏页／溢出排除。跨屏拖框统一物理坐标相交，不限制起始屏，但须按各屏 DPI 绘制。

退出取消临时提升、保留原浮起和保存层级。切应用、新建、导入、工具条动作结束模式。模式外桌面空白属于 Explorer，不接管框选；不全局监听。

<a id="errors"></a>
## 错误与质量边界

启动库错误显示明确模态错误，不建空库掩盖；后台保存／定时失败日志加短暂非激活提示，保存失败保留编辑缓冲并可重试，不能显示已保存。设置内显示可复制错误，历史读失败显示失败及重试，不冒充空历史。跟随深浅主题，高对比优先系统颜色；减少动画、键盘操作和 UI Automation 名称／状态必须可用。

不把 Windows 关机阻止当作数据安全机制；持续提交、事务和备份降低损失，强制结束可能丢未提交输入。托盘隐藏、Explorer 重启、热键被占、屏幕离线不得导致唯一恢复入口消失。无内存指标，不牺牲原生编辑器来减少窗口成本。所有系统边界仍需 Windows 真机验证，未来检查项见 [验证门槛](FEASIBILITY.md#verification)。
