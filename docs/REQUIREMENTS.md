# DeskNodes 功能与交互

本文件统一维护产品行为；视觉数值见 [UI 规格](UI_SPEC.md)，实现机制见 [技术设计](TECHNICAL_DESIGN.md)，文档基线见 [入口](README.md)。

## 产品范围与术语

DeskNodes 是个人本地使用的中文 macOS 桌面待办便签。便签是长期清单容器，事项是清单条目；事项可完成、划掉、排序或删除。划掉表示“不做了”，与完成互斥。

业务日按当前时区和跨天时间划分；业务日结束后生成只读历史快照。自由布局、停靠、单张折叠、全局收起、工具条收缩和临时浮起是不同状态，互不替代。

当前范围不含账号、云同步、Windows／iOS、提醒与截止时间、Markdown 富文本、跨便签拖动事项、历史编辑、隐私锁、屏幕共享自动隐藏、物理删除管理、旧 Tauri 数据自动迁移或分发公证。

<a id="fr-01"></a>
## FR-01 启动、空状态与菜单栏

- 启动读取本机数据库、执行支持的迁移、恢复本机展示偏好并检查跨天。无便签时不创建示例数据，仍保留工具条；只有新建与设置动作可用。
- 菜单栏依次提供“新建便签”“显示工具条”“浮起便签／放回便签”“选择便签…”“历史记录…”“最近删除…”“设置…”和退出。无便签时选择入口禁用。
- “显示工具条”将工具条恢复到已连接显示器的可见区域并展开；不改变便签收起状态。
- 工具条启动时显示完整形态，闲置计时重新开始。便签恢复上次全局收起目标。
- 关闭设置或历史窗口不会退出应用。菜单与设置底部均可退出；退出前提交编辑，组词未结束或保存失败时取消退出。
- 应用为菜单栏常驻应用，没有 Dock 图标。首次登录启动询问见 [FR-12](#fr-12)。

<a id="fr-02"></a>
## FR-02 新建便签与配色

- 工具条、菜单栏、⌘N 与新建全局快捷键进入同一流程。组词期间不执行新建，该入口直接返回。
- 先退出多选；全局收起时先展开，再创建自由便签。新便签为桌面层、无标题、一个空事项，选中后激活应用并聚焦首行。
- 默认尺寸及可选尺寸统一见 [便签几何](UI_SPEC.md#geometry)。未设置过高度时采用固定默认高度；明确保存的“随内容”继续保留。设置只影响之后新建的便签。
- 新建优先在工具条所在屏幕，避开工具条完整展开区域和已显示便签；屏幕放不下时级联摆放，允许重叠。
- 配色优先采用当前未删除便签中使用最少的颜色；并列时从最近创建便签的颜色之后循环选取。用于判断“最近创建”的候选包含保留的已删除便签；色板见 [颜色](UI_SPEC.md#palette)。

<a id="fr-03"></a>
## FR-03 标题、事项与输入

- 标题可省略，空值显示“标题”；折叠摘要优先用标题，否则用第一条事项文字。
- 事项支持新增、编辑、完成／取消完成、划掉／取消划掉、删除和同便签排序。完成与划掉互斥，切换其一会清除另一个；均不立即归档或改变排序。进度总数不含划掉事项。
- 行尾悬停显示划掉、删除与排序手柄。正文使用原生文字编辑、选区与撤销；字号控制见 [FR-14](#fr-14)。
- Return 在当前项后新增并聚焦；组词中的 Return 仅确认输入法。Backspace 仅在空字符串行删除该行。
- 无选区且位于首／末视觉行时，↑／↓ 可切换相邻事项；多行内部先移动光标。⌘Return 切换当前事项完成，⌘⇧X 切换划掉。
- 多行粘贴过滤空行、移除常见列表前缀后拆成事项；第一行插入当前文字选区，后续行依次新增。复选框前缀不会自动设置完成，单行粘贴保持原生行为。
- 输入停顿约 0.4 秒后保存；失焦、导出、跨天和退出等边界提交已完成编辑。普通刷新不覆盖活跃或组词文字；未完成组词不会作为已提交文字写库。
- 失焦后清理多余空白事项，保留可继续输入的一行；这种清理不弹删除提示、不进入历史删除记录。

<a id="fr-04"></a>
## FR-04 选择、删除、撤销与最近删除

### 单张与事项删除

点击便签建立当前选择，选择与键盘焦点分别记录；点击工具条不清除选择。整张删除从便签菜单执行，事项删除从行尾执行；工具条没有删除按钮。删除前提交编辑，组词期间拒绝破坏输入上下文的结构操作。普通删除不弹确认，采用软删除；删除最后一张仍保留工具条。

### 撤销

删除后严格在 `0 ≤ elapsed < 5` 秒内可撤销，恢复原身份、内容与记录状态。多次删除从最新有效操作开始逐次撤销；一次批量删除是一个操作，一次撤销恢复整批。

⌘Z 在删除仍有效且尚未开始新输入时优先撤销删除；开始输入后回到原生文字撤销，提示上的“撤销”在剩余时间内仍可点击。该队列不跨重启，成功导入后清空。多条有效操作并存时提示按操作条目计数，不按批次里的便签数累加。

### 最近删除

菜单栏“最近删除…”或历史窗口顶部切换进入。按删除时间显示最近 `30 × 86400` 秒内的便签和非空事项；打开、重新聚焦或恢复时刷新。

恢复整张会展开桌面，恢复与其同一时刻删除的未归档事项并校正显示器；更早单独删除的事项不自动恢复。单独恢复的事项回到仍存在的原便签末尾。恢复后移除对应内存撤销条目；批次中的其他便签仍可撤销。

恢复不修改封存历史，已归档事项不重新激活。时间窗只是列表范围；底层恢复方法没有单独的期限校验，当前没有永久删除或定时物理清理功能。

<a id="fr-05"></a>
## FR-05 自由布局、折叠与停靠

- 从标题非编辑区域拖动自由便签，跟手移动，释放时保存位置及显示器；正文保留输入。手动缩放关闭自动高度，可通过“随内容调整高度”恢复。
- 单张折叠只显示标题摘要，保持顶部位置；展开恢复保存的展开尺寸，不改变其他便签。
- 菜单“停靠 ▸ 顶部／左侧／右侧”将便签放到其当前显示器的对应边；当前边打勾。“取消停靠”只在已停靠时出现，恢复停靠前自由位置。自由便签靠近边缘不会自动停靠。
- 同边停靠按顺序排布，支持条内排序、拖出、溢出标签与分页。拖出需离开停靠保留带；选中溢出标签可将对应便签提升显示。各方向尺寸和判定带见 [便签几何](UI_SPEC.md#geometry)。
- 设置与菜单栏不再提供整体搬移停靠条的控件；单张菜单是停靠入口。旧字段的兼容处理见 [数据模型](TECHNICAL_DESIGN.md#models)。
- 布局使用系统可用区域，避开菜单栏和 Dock；显示器离线后回退主显示器并校正。移动工具条不会带走自由便签。
- 便签菜单结构为：颜色 → 三层级 → 停靠子菜单及条件显示的取消停靠 → 折叠／展开、随内容调整高度、添加事项 → 选择多张、删除便签。“置顶”仅保留层级组内一项。

<a id="fr-06"></a>
## FR-06 瀑布流整理与分页

主动点击整理后，各屏幕分别按便签持久化顺序规划：每张放入当前占用高度最小的一列，并列取最左列；最短列也放不下时开始新页。统一宽度、间距和内边距见 [便签几何](UI_SPEC.md#geometry)。

高度不统一：自动高度按整理宽度重算内容，手动高度保持原值并受屏幕可用高度限制；单张折叠按标题条高度占位，保留其展开尺寸。停靠便签参与后转为自由便签，内容、颜色、层级和历史不变。

新建、整理及停靠规划避让工具条完整展开目标，即使工具条当前为圆形。工具条之后可能覆盖用户手动摆放的便签；整理是一次性动作，不持续吸回网格。

整理后保存布局与分页关系，当前页归零；多屏共用页码，页数较少的屏幕停留在其最后一页。非当前页便签隐藏，新建便签不属于旧分页映射、默认可见。收起状态下整理会按新布局展开。

<a id="fr-07"></a>
## FR-07 全局收起与展开

工具条“收起／展开”及叠放提示控制整组便签。收起前安全提交编辑，真实便签窗口向工具条旁汇聚并隐藏，保留位置、尺寸、单张折叠和层级；展开仅恢复当前整理页，不重新整理。

工具条完整时显示叠放提示；圆形时隐藏提示，已收起且存在便签才显示数量角标，超过 99 显示“99+”。收起会结束浮起；无便签时清除收起目标，不显示空叠放。

收起目标跨重启保存，过渡动画不保存。快速重复点击可反向操作，以最后请求为准。新建、整理及浮起在收起状态下的行为分别见对应章节。

<a id="fr-08"></a>
## FR-08 工具条方向、磁吸与收缩

工具条五动作固定为新建、浮起／放回、整理、收起／展开、设置；默认竖向自由放置，可在设置切换横向。常规动作不获取文字焦点，主动新建与打开辅助窗口按各自流程激活。

### 拖动与磁吸

完整形态从手柄拖动，圆形从入口拖动；最大轴向位移达到 4pt 判为拖动，不触发之后出现的按钮。释放时优先用指针所在显示器，否则用最后有效屏幕。

仅考虑能放下完整目标的屏幕外边，距外框不超过 81pt 时取最近边；同距优先原边，否则按左、右、上、下。相接显示器的内部边不吸附。拖动中预览完整目标，释放后吸附；形态尺寸及边距见 [工具条规格](UI_SPEC.md#toolbar)。

圆形保持手柄端锚点，沿边按归一化比例恢复；展开时向屏内延伸，必要时沿边平移以保持入口被覆盖。自由位置按中心校正完整外框，磁吸不改变方向。

### 闲置与唤起

- 设置可选关闭／10／15／30 秒，默认 15 秒。仅已吸边、稳定展开、指针离开、无拖动／按住／动画、设置不可见且 VoiceOver 关闭时计时；自由工具条不自动收缩或移动到边缘。
- 操作、唤醒或条件中断后重新等待完整时长。圆形悬停 140ms、单击或辅助功能激活可展开；外部拖放按住经过时不展开。
- 仅悬停唤起且没有点击／滚动就移出时，使用 1.5 秒宽限；有效操作后恢复完整闲置时长。
- 收缩中移入可连续反向，展开中移出先完成展开；按钮只在稳定状态可执行。关闭自动收缩会立即展开；圆形中切方向保持圆形，下次按新方向展开。

<a id="fr-09"></a>
## FR-09 窗口层级与浮起

便签独立保存桌面、普通、置顶三层。桌面层在桌面图标之上、普通应用之下，编辑时可临时提升，失去活动状态后恢复。没有全局常驻置顶开关；升级时清除旧全局置顶偏好并提示一次，不改各便签保存的层级。

浮起由工具条、菜单栏或浮起全局快捷键触发：若已收起先展开，将同一批真实便签原地临时提到最前，激活应用并优先聚焦当前选中便签。再次触发、便签中 Esc、切换应用、全局收起或清空便签时结束；组词、设置录制、警告与文件面板保留自己的 Esc。

浮起不改内容、位置、尺寸或保存层级，不跨重启。有效置顶便签、停靠标签、工具条与叠放提示允许进入全屏空间；设置、历史与普通提示不采用辅助全屏行为。

不使用全局事件监听或辅助功能权限。若系统拒绝激活，Esc 与离开检测可能不可用，仍可用按钮、菜单或快捷键放回；层级不保证覆盖系统高优先级窗口。多选提升与浮起的关系见 [FR-15](#fr-15)。

<a id="fr-10"></a>
## FR-10 跨天、归档与自动备份

默认跨天时间为 04:00，可设 00:00–23:59；按当前时区与公历业务日处理夏令时。启动、约每 30 秒、唤醒、系统时钟／时区变化和相关设置更新时检查，不保证秒级触发。

初次建立检查点不伪造昨日记录。向前跨越时只封存上一个已观察业务日：未完成事项标记顺延至当前日，完成和划掉事项归档并退出实时清单；划掉不顺延。长时间未运行不补造中间日快照。每天最多一份封存记录，不允许更新、删除或补插成员；回拨不反向归档或覆盖。

组词期间延迟并在完成输入后重试。提交编辑、封存、归档、待记录删除清理和检查点推进保持事务一致。每次成功推进后尝试保存自动 SQLite 副本，失败只记录日志；副本规则见 [自动备份实现](TECHNICAL_DESIGN.md#automatic-backup)，恢复操作见 [操作指南](native-build.md#recovery)。

<a id="fr-11"></a>
## FR-11 历史记录

从菜单栏“历史记录…”进入，顶部可切换日历与最近删除。日历周一开始，可前后翻月；选中日期显示该日冻结便签与事项，含删除标记和顺延目标。

日／月完成率使用冻结 completed 次数除以记录的事项次数，包含已删除成员、不含划掉成员；同一事项跨多天出现会重复计数，不按唯一任务去重，也不取每日百分比平均。无分母显示“—”。

历史只读；无快照时显示“当天没有历史记录”，不生成记录或用实时清单代替。最近删除恢复属于 [FR-04](#fr-04) 的独立写操作。

<a id="fr-12"></a>
## FR-12 设置、快捷键与登录启动

设置分组顺序为通用、外观、工具条、新建便签、快捷键、数据；底部退出。一般修改立即生效，没有总保存按钮。分组控制分别引用本文件的对应功能；字号见 [FR-14](#fr-14)，尺寸见 [FR-02](#fr-02)。

新建全局快捷键默认 ⌃⌥N，浮起默认 ⌃⌥F，后者可清除。支持 Control／Option／Shift／Command 加物理 ANSI 字母、数字或 Space，至少含 Control 或 Command；拒绝 ⌥⌘H、⌥⌘D、⌃⌥Space，两快捷键不能相同。录制 Esc 取消，注册冲突保留旧值与绑定。

首次询问登录启动提供“暂不启用／启用”，拒绝后不重复问。仅明确同意或主动设置操作调用系统注册／注销；以 OS 返回的启用、待批准、未注册或错误状态为准。导入的登录意愿不会自动注册系统服务。

<a id="fr-13"></a>
## FR-13 导出、导入与本地数据

所有业务数据在本机保存，无加密功能声明；位置及备份字段归属见 [存储](TECHNICAL_DESIGN.md#storage) 和 [备份协议](TECHNICAL_DESIGN.md#backup)。

导出：完成输入 → 提交有效编辑 → 事务读取完整业务数据 → 保存面板 → 原子写 JSON。取消保存不写文件，已提交的编辑仍保留。

导入：选择 JSON → 版本、引用及 staging 校验 → 确认“替换全部本机数据？” → 尝试候选新建快捷键 → 原子替换业务库 → 重建编辑上下文。无效文件、取消、组词或候选新建快捷键冲突保留旧数据；替换成功后浮起快捷键若被其他应用占用，只提示错误，不回滚已导入数据。

成功导入结束多选与浮起、清除旧删除与文字撤销，并替换业务便签布局。本机展示偏好与系统登录项不随业务库替换。导入本身不立即跨天；后续正常调度可推进导入的旧检查点。兼容版本与字段缺省值见协议，操作步骤见 [恢复指南](native-build.md#recovery)。

<a id="fr-14"></a>
## FR-14 文字大小

设置 → 外观 → 文字大小提供四档及实时示例；所有便签统一应用。便签中 ⌘+／⌘= 放大一档、⌘− 缩小、⌘0 恢复标准，到端点不再变化。

字号、行高、完成圆圈、标题区和底部操作区一起适配，宽度与内边距保持原值。自动高度重算，固定高度保持并在内部滚动，停靠重新布局；工具条、设置和历史文字不受影响。具体字号及缩放规则只在 [排版](UI_SPEC.md#type) 维护。

组词期间拒绝切换并回显实际档位。选择保存在本机偏好，重启恢复、不进入 JSON 备份；不支持单张字号。

<a id="fr-15"></a>
## FR-15 多选与批量删除

### 入口与操作

- ⌘单击便签进入并选中该张；⌘从便签按住拖动可在同一手势中开始框选。
- 便签菜单“选择多张…”进入并选中该张；菜单栏“选择便签…”进入但不预选。
- 模式内单击便签切换勾选，从便签或覆盖层空白处拖动按矩形相交选择，普通拖框替换选择，⌘拖框追加；单击空白清空选择但不退出。
- ⌘A 全选当前可见便签；⌫／Delete 删除所选；Esc 或“完成”退出。无选择时删除按钮禁用。删除后退出，不弹确认，整批撤销见 [FR-04](#fr-04)。

### 状态与边界

进入前检查组词；收起时先展开。模式中真实便签临时提升，每屏覆盖层接收空白拖动，正文不可编辑，单击不放置光标。批量勾选样式与普通当前选择分别显示，见 [选择反馈](UI_SPEC.md#selection)。

仅当前可见窗口可被框选或全选；折叠与已显示的停靠便签可选，其他整理页与停靠溢出隐藏窗口不可选。当前实现按全局屏幕坐标求相交，没有把拖框限制在起点显示器。

退出后取消临时提升，保留原浮起状态与每张保存的层级。切换其他应用、新建、导入或点击工具条动作会结束模式。模式外桌面空白属于访达，不能在那里直接框选便签；不使用全局事件监听。

## 错误与质量边界

启动库错误可显示模态错误；后台保存／定时错误使用日志和短暂非激活提示。设置错误显示在设置内，历史读取失败显示失败与重试，不冒充空数据。深浅色跟随系统，支持减少动态效果与关键控件辅助名称。
