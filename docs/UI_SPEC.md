# DeskNodes Windows UI 规格

本文件定义视觉目标，未在 Windows 渲染验收。继承 feat-mac 现行 UI_SPEC 的纯色、柔和配色、留白和紧凑卡片，不把历史效果图中的透明材质、删除工具按钮或比例当作现行规格。行为见 [需求](REQUIREMENTS.md)，系统实现限制见 [可行性](FEASIBILITY.md)。

## 单位与 Windows 原生品质

所有应用内容尺寸为 Windows DIP（96 DIP／英寸），按每屏 DPI 换算像素；不是将 macOS pt 当作物理点。以下数值是来源视觉节奏在 Windows 的初始目标。字体度量、中文 fallback、非客户区、系统缩放和触摸命中需真机校准，不能机械保证像素一致。

字体首选 Segoe UI，中文 fallback Microsoft YaHei UI；不随包伪造苹方。正文保持系统文字服务和清晰光标；进度使用等宽数字。Windows 标准菜单、文件对话框和设置／历史标题栏保留系统行为、右侧窗口按钮；不画红黄绿交通灯、不复制 macOS 菜单栏。便签与工具条可以定制外壳，命中、阴影、调整大小和高 DPI 清晰度仍须符合 Windows 使用习惯。

<a id="selection"></a>
## 选择与状态反馈

普通当前选中描边 1.5 DIP，使用自身色系；应用后台不透明度降至 45%。多选采用系统强调色资源，2 DIP 描边、左上 22 DIP 勾选圆，替代普通描边。每屏多选覆盖层黑色 10%，框选矩形强调色填充 14%＋1 DIP 描边。高对比时不用低透明度作为唯一反馈。

鼠标 hover、键盘 focus 和当前选择分开：键盘可见焦点环最少 2 DIP，不能只靠阴影；完成圆圈给出勾选及可访问状态，划掉给出独立名称。后台描边弱化不能隐藏操作可用性。圆角／阴影是装饰，不得形成透明点击遮挡区。

<a id="type"></a>
## 排版与字号

| 档位 | 标题 | 事项 | 次要 |
|---|---:|---:|---:|
| 小 | 15 | 13 | 11 |
| 标准 | 16 | 14 | 12 |
| 大 | 18 | 16 | 14 |
| 特大 | 20 | 18 | 15 |

标题 Semibold、事项 Regular；添加事项用次要字号＋1。长度比例＝事项字号／14，缩放长度四舍五入到整数 DIP。标准单行事项高 32、换行节奏 22、上下各 5，圆圈直径 16、文字间隔 11；行高、换行、圆圈及间距、展开标题／底部区按比例缩放。折叠条保持固定，标题 14 Semibold。

圆圈对齐首行，不对齐整段中心。行尾划掉和删除各 22×22、间距 2、悬停底板圆角 6、图标 12；排序手柄宽 14，正文预留尾宽 64。键盘聚焦显示相同操作，不因悬停改变标题宽度或盖住正文。触摸目标可扩展至相邻空白但不能重叠；若触摸小样失败，应提供显式行菜单作为替代，不能仅放大图标破坏排版。

WPF 的 DIP 字号和 Windows 系统文本缩放不是同一设置；实现时需要明确接入辅助文本缩放并重新量高。系统较大文本下允许辅助窗口滚动、便签内部滚动，优先完整显示而非裁字，需 Windows 真机验证。

## 便签几何

| 项目 | 目标 DIP |
|---|---|
| 新建默认 | 288×240 |
| 新建宽度 | 240／288／340／400 |
| 新建高度 | 随内容／200／240／300／400 |
| 自由尺寸范围 | 200×120 至 400×600，仍受工作区限制 |
| 自动高度上限 | 480，再受工作区裁限 |
| 内边距／展开圆角 | 18／13 |
| 标准标题区／底部区 | 50／44，列表另留底部空白 |
| 折叠高／圆角 | 32／10 |
| 整理宽／间距／屏内边距 | 288／18／22 |
| 左右停靠宽 | 288 |
| 顶部停靠宽×高 | 220×260，可见屏高不足 700 时高 200 |
| 停靠间距／溢出区 | 12／96 |
| 屏幕安全内缩／脱离带 | 8／约 48 |

从上到下为手柄／更多、标题与计数、可滚动事项、分隔线与添加。更多悬停或键盘聚焦出现，折叠态与计数共用右侧位置；置顶标记只代表保存层级，不表示临时浮起。自由缩放边应保留 Windows 标准指针与可命中宽度，实际非客户区不得从内容 288 宽中重复扣除。

Windows 11 的 DWM 圆角是系统离散偏好，不保证正好 13 DIP；推荐内容内部按 13 设计，外壳接受系统圆角，先验证边缘不漏底。若必须精确圆角，可自定义裁剪，但会增加阴影、缩放和 IME 验证成本；不使用未公开 backdrop 属性。

<a id="toolbar"></a>
## 工具条与提示

胶囊短边 64、圆角 32、内缩 6、端帽额外 10、手柄长轴 24。竖按钮长轴 52、数量区 32，自然高 348／带分页 376；横按钮 60、数量区 68，自然宽 424／带分页 488。小屏滚动内容、保留手柄。圆形直径 48、吸边距 8；标签 12 Medium、图标约 17、数量约 11。动作顺序及时间规则只见需求。

叠放提示最多三层颜色加数量，优先右侧，否则左侧。删除提示 296×46，主屏工作区底部上方 28；多选条 380×46 同位置，含计数、全选、删除、完成；两者同时出现时错开，删除提示上移到 92。错误宽 360、高 44–72，底部上方 80、最多三行，完整错误可从日志／设置读取。均按实际工作区裁限，不覆盖任务栏入口。

<a id="windows"></a>
## 设置与历史

设置初始**内容区** 760×576，可滚动，横 padding 40、纵 20、组间距 16，组标题 12 Semibold，行最小高 40、左右 14、圆角 10，字号示例行最小高 44。默认不提供自由缩放；系统较大文本或较小工作区必须适配，不把最初尺寸当不可越界外框。错误在底部可复制。

历史／最近删除复用普通可缩放窗口，初始内容 1040×656、目标最小 900×656；小工作区允许降低约束并滚动。顶部分段，日历区宽 400，横／纵 padding 28／24，月与详情标题 20 Semibold，日格高 46／圆角 9，进度 22×3，月完成率 24，详情横 padding 32。Windows 标题栏额外占用，不照抄 Mac 外框。

历史浅色背景 #FBFAF8、弱底 #EFEDE8、选中 #2F2C27、进度 #4F7A64、轨道 #E4E1DA、顺延文字 #6B5A2E／底 #F3E9C9。来源深色映射只引用 Mac 源码，未提供完整数值；Windows 暂按本文件深色语义资源设计，不假称复制其实现，实施时补齐实际色表和对比度检查。最近删除按便签／事项分组，原色、标题、时间、前四项、超出“还有 N 项”；时间用“移出列表”。

便签和工具条保持纯色；设置可选择公开 DWM Mica、临时面板可选择 Desktop Acrylic，关闭透明效果、远程会话或效果不可用时退回纯色。材质是增强，不决定可读性。Win11 22621 提供 DWM_SYSTEMBACKDROP_TYPE，但 WPF 壳层能否正确承载仍需小样。[公开材质枚举](https://learn.microsoft.com/en-us/windows/win32/api/dwmapi/ne-dwmapi-dwm_systembackdrop_type)

<a id="motion"></a>
## 动效与可访问性

新建 0.20 秒、删除 0.18、整理 0.26、全局汇聚 0.28；工具条磁吸 0.20、形态变换 0.26。展开外壳 180ms＋控件淡入 80ms，收缩反序；文字按最终布局，不逐帧缩放重排。拖动跟手不加位置缓动。

系统关闭客户区动画或用户选减少时取消空间运动／直接定位，淡变最多 0.12 秒；状态与命中立即一致，不等待动画才能操作。关键控件通过 UI Automation 提供名称、角色、完成／选中／展开状态；Tab 顺序可预测，非激活工具条必须有托盘／键盘等价入口。读屏模式默认不自动收缩，检测不完整时由显式设置保证可达。

所有主题、DPI、字体、触摸、Narrator、透明效果回退和动效数值均为待验证设计，没有截图／原型验收结果。
