# DeskNodes UI 规范与原型说明

日期：2026-11-12；当前依据为 DesignTokens.swift、Theme.swift 及 AppKit／SwiftUI 视图。所有应用尺寸均为 macOS 逻辑 pt；浏览器原型用 CSS px 表达近似比例，不可反推 Retina 像素。

## 1. 原型入口与使用方法

打开本目录 [UI_PROTOTYPE.html](UI_PROTOTYPE.html)。无需安装依赖或访问网络，页面只读写本次演示内存。

页面顶部是**文档控制区**：桌面、浮起、历史、最近删除、设置、明暗切换、恢复示例。它不属于原生应用。桌面中的五按钮胶囊才是产品工具条。

可操作内容包括：新建便签、选择、从菜单删除、五秒撤销、完成勾选、划掉、编辑标题／事项、添加事项、同便签排序、卡片菜单、单张折叠、整理、全局收起／展开、浮起、工具条方向、演示吸边及圆形入口、查看历史 fixture、恢复演示删除内容、查看设置和导入导出流程说明。

原型使用 HTML 表单控件近似原生编辑，不实现 NSTextView 输入法协议、SQLite、Carbon、SMAppService 或真实 Space／全屏层级；不使用浏览器表现证明原生应用验收通过。原型不包含真实备份文件读写，导入导出按钮展示流程说明。

## 2. 信息架构

```text
菜单栏（常驻）
├─ 新建 / 显示工具条 / 浮起便签
├─ 停靠 → 旧布局管理
├─ 历史记录 → 日历 | 最近删除
├─ 最近删除 → 同一历史窗口的最近删除模式
├─ 设置 → 通用 / 停靠条 / 工具条 / 新建便签 / 快捷键 / 数据 / 退出
└─ 退出

桌面
├─ 独立工具条 → 五动作 / 数量 / 必要时分页
├─ 自由便签、兼容停靠卡片和标签
├─ 全局收起的叠放提示或圆形数量角标
└─ 删除撤销提示、错误提示

浮起 → 同一批真实便签临时置顶（含全屏应用），无独立面板
```

## 3. 当前视觉基础

便签与工具条使用不透明纯色，纸感来自比例、低饱和背景、轻描边与柔和阴影；不使用纹理、胶带或装饰插画。删除／错误 toast 当前使用 NSVisualEffectView 的 popover 材质，是纯色便签原则之外的实际实现细节。

字体为系统字体和中文 fallback；数字在需要处使用等宽。标题 16pt 半粗，事项 14pt，次要信息 12pt；工具条标签 12pt 中等、图标约 17pt、数量约 11pt。

### 3.1 七色背景

- 宣纸 `paper`：浅色 `#F6F1E7`，深色 `#2B2822`。
- 柠黄 `lemon`：浅色 `#FAF0C8`，深色 `#35301A`。
- 杏 `apricot`：浅色 `#FBE7D6`，深色 `#3A2A20`。
- 樱 `cherry`：浅色 `#F7E1E4`，深色 `#3A2328`。
- 薰衣草 `lavender`：浅色 `#ECE6F5`，深色 `#2A2536`。
- 雾蓝 `mist`：浅色 `#E3ECF5`，深色 `#1F2A36`。
- 薄荷 `mint`：浅色 `#E2F0E8`，深色 `#1E2E26`。

色板没有石墨；历史素材中出现的第八色不能作为当前可选项。

### 3.2 文字与工具条

- 正文：浅 `#1F1F1F` / 深 `#EDEBE6`。
- 次要文字：浅 `#5F5A52` / 深 `#B3ADA2`。
- 完成文字：浅 `#6F6A61` / 深 `#A39D92`。
- 强调色：浅 `#6E9A68` / 深 `#8DB887`；选择描边浅色使用 `#8FB487`。
- 工具条底色：浅 `#F6F5F1` / 深 `#272A2E`。
- 工具条前景：浅 `#24282D` / 深 `#F2F4F6`。
- 工具条次要色：浅 `#5C636B` / 深 `#BDC4CC`。
- 工具条禁用色：浅 `#878D94` / 深 `#858D97`，仍保持可辨认。
- 工具条描边：浅 `#D1D2CE` / 深 `#50555C`。

## 4. 页面 P01：桌面与工具条

### 4.1 工具条

展开为胶囊，短边 64、半径 32、内缩 6、端帽额外留白 10、手柄长轴占位 24。五个按钮顺序不能变：新建、浮起／放回、整理、收起／展开、设置。

竖向每按钮长轴 52，数量 32；自然高度为 348，带分页 376。横向每按钮长轴 60，数量 68；自然宽度 424，带分页 488。小屏用滚动内容而不是压字或裁掉最长标签。圆形入口直径 48；磁吸安全间距 8。

浮起中按钮显示“放回”并保留强调底板。没有便签时显示 0 张，浮起、整理、收起禁用，不能出现大空白主窗口。

工具条不获取键盘 key focus；按钮需提供清楚的悬停、按下和禁用语义。VoiceOver 圆形入口名称为“展开 DeskNodes 工具条”。

### 4.2 自由便签

```text
┌─────────── 顶部拖动手柄 / 更多 ────────┐
│ 标题（可选）                  完成数   │ 头部 50
│ ○ 事项第一行                           │
│   第二行，圆圈仍对齐第一行              │
│ ● 已完成事项（低强调色）                │
│ ◌ 划掉事项（更淡＋删除线）       ⊖ × ⠿ │
├───────────────────────────────────────┤
│ ＋ 添加事项                            │ 底部 44
└───────────────────────────────────────┘
```

默认宽 288，横向 padding 18，圆角 13；自动高 120–480，手动范围一般为 200×120 至 400×600。标题编辑区域按文本需要伸展，但悬停“更多”不能造成标题跳动。完成数使用低强调文字；单张置顶有 pin 提示。

事项一行高 32，换行节奏 22，上下各 5；圆圈直径 16，与文字间距 11。圆圈点击区覆盖首行高度；划掉、删除（各 22×22，间距 2，悬停有 6pt 圆角底板，删除悬停变红，图标 12pt）与排序手柄（宽 14）位于行尾，默认隐藏、悬停出现，预留 64 宽度，不能覆盖正文。圆圈视觉中心对齐第一行，不能对齐整段中心。

选中用细鼠尾草色边框；选择与文字焦点分别记录。正文区域可滚动，底部添加入口不随内容消失。

### 4.3 折叠、菜单、汇聚

单张折叠高 32、圆角 10，只显示标题摘要和必要操作。卡片菜单提供七色、桌面／普通／置顶、停靠顶部／左侧／右侧／移出停靠、置顶切换、折叠、自动高度、添加事项、删除便签。正文原生文字编辑区保留其原生菜单语义。

全局收起时最多三层小色块加数量，不展示正文；优先位于工具条右侧，不足则左侧。工具条圆形时隐藏叠放提示，仅在便签已收起且有内容时显示数量角标。

### 4.4 提示与反馈

删除 toast 约 296×46，出现在主屏可用区底部上方 28，文案为“已删除便签”“已删除事项”或“已删除 N 项 · 可逐项撤销”，右侧“撤销”。错误消息为“无法完成操作：…”；不能把后台错误弹成持续打断编辑的模态框。

## 5. 页面 P02：浮起

没有新窗口：桌面上的便签原地成为有效置顶（floating 层级、可进入全屏 Space），尺寸、位置、折叠与颜色都不变。工具条“浮起”按钮切为“放回”并显示强调底板；菜单栏项同步为“放回便签”。

原型在全屏示意背景上原地显示同一批便签，用于说明“原地前置、同一份数据”，不模拟真实窗口层级、激活和 Esc 监听。

## 6. 页面 P03：历史窗口

原生初始内容尺寸 1040×656，可调整，最小 900×656。顶部统一工具栏放“日历／最近删除”。

左侧月历区域宽 400，内边距约横 28／纵 24；月份标题 20 半粗，左右翻月按钮，周一到周日排列。日格高 46，选中为深底浅字，今天用较淡背景；有分母时显示 22×3 进度细线。

左下为本月完成率（24pt）及“共 X 项，完成 Y 项”。右侧横向 padding 32，日期标题、完成计数，按便签分组的冻结事项，删除与顺延用低干扰 badge。无数据明确显示，不从 live 自动补内容。

历史窗口浅色主题常量：背景 `#FBFAF8`，弱底 `#EFEDE8`，选中底 `#2F2C27`，进度 `#4F7A64`，轨道 `#E4E1DA`，顺延文字 `#6B5A2E`，顺延底 `#F3E9C9`。原生深色对应值由 `HistoryColors` 动态提供；这些规则用于源码与文档的静态核对。

历史只读；历史完成事项采用完成圆圈，删除状态使用删除线与“已删除”标记。不要把桌面已完成文字的所有样式机械复制到历史。

## 7. 页面 P04：最近删除

复用历史窗口，顶部切换到最近删除；标题 20 半粗，说明最近 30 天可恢复且历史快照不受影响。

按“便签 · 数量”“事项 · 数量”分组，便签卡片使用原颜色、标题、删除时间、前四条预览与恢复按钮；更多项显示“还有 N 项”。单独事项显示来源便签、时间和恢复。空列表显示“最近 30 天没有删除的内容”。

日期说明为“删除于 今天／昨天／M月d日 HH:mm · N 天后移出列表”。“移出列表”不能写成永久删除承诺。

## 8. 页面 P05：设置窗口

初始内容 760×576，普通标题／关闭窗口，内容滚动；当前不提供普通 resize 手柄。页面横向 padding 40、纵向 20，分组间距 16。分组标题 12 半粗，条目最小高 40、左右 padding 14、分组圆角 10。

从上至下：

1. 通用：开机时自动启动；每天跨天时间。下面显示系统登录项说明、跨天范围、查看系统登录项入口。
2. 停靠条：顶部／左侧／右侧分段；显示器选择，保留不可用显示器的回退说明。
3. 工具条：竖向／横向；关闭／10／15／30 秒自动收缩。
4. 新建便签：宽度 240／288／340／400 分段；高度 随内容／200／300／400 分段；说明只影响之后新建的便签。
5. 快捷键：新建便签（默认 ⌃⌥N）、浮起便签（默认 ⌃⌥F，可“清除”显示“未设置”）各一行，符号化展示和“录制…”；录制时显示取消与 Esc 提示，另一行录制按钮禁用。下方说明浮起的放回方式。
6. 数据：备份（JSON），导入…／导出…。
7. 底部右侧：“退出 DeskNodes”按钮（⌘Q），走与菜单退出相同的组词检查与提交。

错误消息显示在底部并允许选择复制。修改一般立即生效；导入替换必须先校验后确认。原型使用表单解释这些设置，系统动作只显示流程说明。

## 9. 动效与可访问性

- 新建 0.20 秒，删除 0.18，整理 0.26，全局汇聚 0.28。
- 工具条磁吸 0.20，形态 0.26；完整展开先 180ms 外壳变化，再 80ms 控件组淡入；收缩反序。
- 工具条文字用最终坐标布局，不逐帧重排或缩放。形态切换采用直线 easeInEaseOut，无弹跳。
- 减少动态效果时取消空间运动或直接定位，通用淡变可缩为 0.12 秒；原型遵循浏览器对应媒体偏好。
- 功能按钮必须有中文标签、可识别的禁用态；完成按钮有状态名称；菜单、圆形入口、恢复和月份导航有辅助说明。

## 10. 与旧五组原型的映射及局限

旧 01 桌面总览对应当前 P01，但默认布局和尺寸已更新；旧 02（边缘唤出）已由 P02 浮起取代；旧 03 的状态菜单合并到 P01；旧 04 对应 P03 并新增 P04；旧 05 对应 P05 且增加工具条设置。

原型的浏览器导航、演示吸边／即时收缩、说明弹窗均有独立标识。原型拖动只简化演示左边缘吸附，整理固定三列，不实现原生容量分页；卡片不提供手动尺寸调整、完整辅助功能或所有键盘导航。真实四边锚点、拖动阈值、多屏拓扑、输入法 marked text、停靠溢出、完整分页容量、系统热键和登录项仍需在原生应用按 [验收清单](ACCEPTANCE.md) 检查。原型不实现业务日调度和持久化。
