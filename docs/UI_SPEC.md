# DeskNodes UI 规格

只维护视觉与布局数值，依据 [DesignTokens.swift](../Sources/DeskNodesCore/DesignTokens.swift)、[Theme.swift](../Sources/DeskNodesApp/Theme.swift) 及原生视图。操作规则见 [功能与交互](REQUIREMENTS.md)。应用尺寸单位均为 macOS 逻辑 pt。

<a id="palette"></a>
## 颜色

便签与工具条为不透明纯色；提示采用 popover 材质。浅／深色跟随系统，字体采用系统字体及中文 fallback。

### 便签背景

- 宣纸 `paper`：浅色 `#F6F1E7`，深色 `#2B2822`。
- 柠黄 `lemon`：浅色 `#FAF0C8`，深色 `#35301A`。
- 杏 `apricot`：浅色 `#FBE7D6`，深色 `#3A2A20`。
- 樱 `cherry`：浅色 `#F7E1E4`，深色 `#3A2328`。
- 薰衣草 `lavender`：浅色 `#ECE6F5`，深色 `#2A2536`。
- 雾蓝 `mist`：浅色 `#E3ECF5`，深色 `#1F2A36`。
- 薄荷 `mint`：浅色 `#E2F0E8`，深色 `#1E2E26`。

### 墨色与工具条

- 正文：浅 `#1F1F1F`／深 `#EDEBE6`。
- 次要文字：浅 `#5F5A52`／深 `#B3ADA2`；完成文字：浅 `#6F6A61`／深 `#A39D92`。
- 强调色（完成填充、撤销）：浅 `#6E9A68`／深 `#8DB887`。
- 工具条底色：浅 `#F6F5F1`／深 `#272A2E`；前景：浅 `#24282D`／深 `#F2F4F6`。
- 工具条次要色：浅 `#5C636B`／深 `#BDC4CC`；禁用：浅 `#878D94`／深 `#858D97`；描边：浅 `#D1D2CE`／深 `#50555C`。

<a id="selection"></a>
### 选择反馈

普通选中描边为 1.5pt，采用便签自身色系；应用后台时不透明度降为 45%。浅／深选中色分别为：

- 宣纸：`#B59E74`／`#C4B08A`。
- 柠黄：`#C9A93A`／`#D6BE5C`。
- 杏：`#D9905F`／`#E0A47E`。
- 樱：`#CF7F90`／`#DB98A6`。
- 薰衣草：`#9A82C9`／`#B5A2DE`。
- 雾蓝：`#6F97C4`／`#92B4DA`。
- 薄荷：`#6FA585`／`#8FC4A3`。

多选勾选采用系统 `controlAccentColor`，不是固定蓝色：选中描边 2pt，左上角勾选圆 22pt，模式内替代普通选中描边。每屏覆盖层黑色 10% 不透明度，框选矩形为系统强调色 14% 填充及 1pt 描边。

<a id="type"></a>
## 排版

四档按“小、标准、大、特大”排列：

- 小：标题 15、事项 13、次要文字 11。
- 标准：标题 16、事项 14、次要文字 12。
- 大：标题 18、事项 16、次要文字 14。
- 特大：标题 20、事项 18、次要文字 15。

标题半粗，事项常规；进度数字等宽。“添加事项”字号为对应次要字号 +1。比例使用事项字号 ÷ 标准事项字号，缩放长度四舍五入为整数点；不使用提案中的近似比例常量。

标准单行事项高 32，换行节奏 22，上下各 5；圆圈直径 16、文字间隔 11。行高、换行节奏、圆圈及间距、展开标题区和底部区按上述比例缩放。折叠标题条保持固定大小，标题为 14pt 半粗。

行尾划掉与删除各 22×22，间距 2，悬停底板圆角 6，图标 12；排序手柄宽 14，预留尾部宽 64。圆圈对齐首行文字，不能对齐整段中心；悬停不得改变标题宽度或覆盖正文。

<a id="geometry"></a>
## 便签几何

- 新建默认 288×240；宽度选项 240／288／340／400，高度选项 随内容／200／240／300／400。
- 常规自由尺寸范围 200×120 至 400×600；自动高度上限 480，实际还受可用屏幕高度裁限。
- 内边距 18，展开圆角 13；标准标题区高 50，底部区高 44，列表另有底部留白；折叠高 32、圆角 10。
- 整理统一宽 288，列间及上下间距 18，屏幕内边距 22。布局方式见 [FR-06](REQUIREMENTS.md#fr-06)。
- 左／右停靠宽 288；顶部停靠宽 220、高 260，可见屏高不足 700 时高 200。停靠间距 12、溢出区域 96；屏幕安全内缩 8，脱离保留带约 48。

便签从上到下为拖动手柄／更多、标题及完成计数、可滚动事项、分隔线与添加入口。更多按钮在悬停时出现，折叠态与计数共用右侧位置。置顶标记只表示已保存的单张层级。

<a id="toolbar"></a>
## 工具条与提示

工具条胶囊短边 64、圆角 32、内缩 6、端帽额外留白 10、手柄长轴占位 24。竖向按钮长轴 52，数量区 32；自然高 348，带分页高 376。横向按钮长轴 60，数量区 68；自然宽 424，带分页宽 488。小屏滚动内容并保留手柄。

圆形入口直径 48，吸附边距 8。按钮标签 12pt 中等，图标约 17pt，数量约 11pt；动作顺序、空状态和计时规则只在 [FR-08](REQUIREMENTS.md#fr-08) 维护。

全局叠放提示展示最多三层颜色与数量，优先在工具条右侧，不足时在左侧。

删除提示尺寸 296×46，主屏可用区底部上方 28；多选操作条 380×46，同位置，包含选择计数、全选、删除、完成。错误提示宽 360，高 44–72，底部上方 80，最多三行。撤销时限和提示计数口径见 [FR-04](REQUIREMENTS.md#fr-04)。

<a id="windows"></a>
## 设置与历史窗口

### 设置

初始内容 760×576，普通标题与关闭按钮、内容可滚动，无常规 resize 手柄。横向 padding 40、纵向 20，分组间距 16；分组标题 12pt 半粗，条目最小高 40、左右 padding 14、圆角 10。字号示例行最小高 44。分组与控件功能见 [FR-12](REQUIREMENTS.md#fr-12)，错误文字位于底部并可复制。

### 日历与最近删除

复用同一窗口，初始内容 1040×656、最小 900×656，可缩放，顶部工具栏放分段切换。日历区宽 400，横／纵 padding 28／24；月份与详情标题 20pt 半粗，日格高 46、圆角 9，进度线 22×3。月完成率数字 24pt，右侧详情横向 padding 32。

历史浅色背景 `#FBFAF8`、弱底 `#EFEDE8`、选中底 `#2F2C27`、进度 `#4F7A64`、轨道 `#E4E1DA`、顺延文字 `#6B5A2E`、顺延底 `#F3E9C9`；深色映射由 [HistoryColors](../Sources/DeskNodesApp/HistoryWindow.swift) 提供。

最近删除按便签／事项分组，便签显示原色、标题、时间及前四条预览，更多显示“还有 N 项”。时间说明使用“移出列表”，避免暗示永久删除。恢复规则见 [FR-04](REQUIREMENTS.md#fr-04)，历史统计见 [FR-11](REQUIREMENTS.md#fr-11)。

<a id="motion"></a>
## 动效与辅助功能

新建 0.20 秒、删除 0.18、整理 0.26、全局汇聚 0.28；工具条磁吸 0.20、形态转换 0.26。完整展开先用 180ms 改外壳，再用 80ms 淡入控件；收缩反序。文字按最终坐标布局，不逐帧缩放或重排。

减少动态效果时取消空间运动或直接定位，通用淡变可缩为 0.12 秒。完成、菜单、恢复、月份导航、圆形入口等关键控件提供辅助名称和状态；禁用态仍需可辨认。

<a id="prototype"></a>
## 演示边界

[UI_PROTOTYPE.html](UI_PROTOTYPE.html) 只保留一套当前外观，覆盖便签、菜单、停靠、多选、字号和瀑布流；不再附带旧版对比与重复需求清单。

它使用内存数据与 CSS px 近似比例，刷新重置；不模拟原生输入法、SQLite、系统服务、全屏与多屏，也不提供完整历史、最近删除、分页或工具条收缩状态机。未实现的按钮应明确标为说明操作。原型不是应用行为的另一份规范，原生验证见 [验收](ACCEPTANCE.md)。
