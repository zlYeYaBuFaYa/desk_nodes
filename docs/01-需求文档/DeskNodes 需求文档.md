# DeskNodes 桌面便签 · 需求文档

2026-11-05

## 1. 产品概述

DeskNodes 是一款跨平台桌面便签，用来记录每天的日常待办：每张便签是一个独立的小窗口，按分类承载当天事项，并可按日期回看完成情况。

**平台**：macOS 12+、Windows 10/11。Linux 暂不支持，技术选型保留后续扩展的可能。

**目标用户**：习惯把当天要做的事写在手边、希望一眼看到待办的个人用户。

**设计原则**（按优先级）：

1. **美观优先**：低饱和配色、柔和阴影、克制的动效，放在桌面上本身就是一件好看的东西。
2. **轻**：打开即用，无账号、无同步、无多余设置；内存目标为 5 张便签同时显示 < 200 MB，以原型实测为准。
3. **快**：新建便签、添加事项都能纯键盘完成，一步到位。
4. **可靠**：所有改动即时自动保存，崩溃或断电不丢数据。

**不做的事**：账号与云同步、多人协作、移动端、富文本与附件、提醒推送（V1）。

## 2. 核心概念

便签是长期存在的分类，事项属于某一天；便签窗口默认只显示“今天”的事项。

| 概念 | 含义 | 生命周期 |
| --- | --- | --- |
| 便签 | 一个分类窗口，如“工作”“生活”，有颜色、位置、大小 | 长期存在，直到用户删除 |
| 事项 | 便签里的一条待办，可勾选完成 | 归属某一天；当天删除即消失 |
| 业务日 | 用于划分“今天”的日期 | 默认 00:00 换日，可设为 00:00–06:00 任一整点 |
| 历史 | 过去每一天各便签事项的快照 | 前一天可补勾，更早日期只读；永久保留（可手动清理） |

**换日规则**

- 到达换日时间时，所有便签自动切换到新的一天，无需重启。
- 前一天未完成的事项**自动顺延**到今天，事项上显示小标记“顺延 N 天”；历史中该事项在原日期记为“未完成”。
- 设置中可关闭自动顺延；关闭后未完成事项只留在历史里。
- 应用关闭期间跨过了多天，下次启动时一次性完成换日：中间日期不生成记录，事项只在原日期记一次“未完成”，N 按实际天数累加。

**删除规则**：事项只有“未完成 / 已完成 / 删除”三种处理，不设“放弃”状态。今天删除的事项不进入历史；删除顺延事项时，它在过去日期的“未完成”记录保留。

## 3. 功能需求

V1 共 6 组功能，标 P0 的为首版必须，P1 可随后补齐。

### 3.1 便签管理

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 新建 | 托盘菜单或快捷键新建；默认取下一个未用过的颜色，出现在屏幕中央偏右，标题自动聚焦待输入，回车后焦点跳到事项输入行；8 色用完后按顺序循环 | P0 |
| 重命名 | 双击标题直接编辑，回车确认，Esc 取消 | P0 |
| 换色 | 便签右上角色点，点开 8 色色盘，即时生效 | P0 |
| 隐藏 | 点标题栏“–”隐藏窗口，数据不变，可从托盘或管理面板恢复 | P0 |
| 删除 | 在“更多”菜单中删除，弹出确认；今天的事项一并删除；历史记录保留，历史中该便签名称显示为灰色 | P0 |
| 置顶 | 图钉按钮切换“始终置顶”，每张便签独立设置 | P0 |
| 移动与缩放 | 拖动标题栏移动，拖边缘缩放；最小 220×160，最大 600×900 | P0 |
| 记忆状态 | 位置、大小、显隐、置顶在重启后恢复；显示器变化导致窗口在屏幕外时自动移回可见区 | P0 |
| 折叠 | 在“更多”菜单中折叠为仅标题栏，再次选择展开（不用双击，避免与双击重命名冲突） | P1 |

便签窗口不出现在任务栏、Dock 和 Alt+Tab / ⌘Tab 切换列表中，只通过便签本身、托盘和快捷键访问（P0）。

### 3.2 事项管理

| 功能 | 说明 | 优先级 |
| --- | --- | --- |
| 添加 | 便签底部常驻输入行，回车添加并保留焦点，连续录入 | P0 |
| 编辑 | 单击事项文字进入编辑，回车或失焦保存 | P0 |
| 完成 | 点圆形勾选框；文字变浅加删除线，0.3 秒后下沉到“已完成”分组 | P0 |
| 取消完成 | 再点勾选框，回到未完成列表末尾 | P0 |
| 删除 | 悬停显示删除按钮，或选中后按 Delete；底部提示条可 5 秒内撤销 | P0 |
| 排序 | 悬停事项时左侧出现拖动手柄，拖动手柄调整未完成事项顺序；单击文字仍为编辑，两者互不冲突 | P0 |
| 已完成分组 | 默认折叠，显示“已完成 3”，点开查看 | P0 |
| 移动到其他便签 | 右键菜单“移动到…” | P1 |

单条事项为纯文本，最长 200 字，自动换行；网址自动识别为可点击链接（P1）。

**明天分组**（P1）：每张便签底部有一个默认折叠的“明天”分组，可提前添加事项；换日时自动并入今天的未完成列表。便签内自上而下依次为：未完成事项、输入行、已完成分组、明天分组。

### 3.3 换日与顺延

按第 2 节规则执行（P0）。换日时便签内容淡出淡入切换，不弹窗打扰。

### 3.4 历史查看

- **入口**：托盘菜单“历史”，或管理面板“历史”页（P0）。
- **日历视图**：按月显示，每天一个色块，颜色深浅表示完成率（0%、1–49%、50–99%、100% 四档），无事项的日子留空（P0）。
- **日详情**：点某天，右侧按便签分组列出当天事项及完成状态，顶部显示“完成 8 / 10”（P0）。
- **编辑范围**：更早日期不可编辑；前一天的事项可补勾或取消完成，照顾“做完了忘记勾”的情况；若该事项已顺延到今天，今天的顺延副本随之自动移除（P0）。
- **统计**：本周 / 本月完成率与连续达成天数（P1）。

### 3.5 托盘、快捷键与管理面板

托盘（macOS 为菜单栏图标）菜单：

- 新建便签
- 便签列表：每项前打勾表示显示，点击切换显隐
- 显示全部 / 隐藏全部
- 历史…、设置…
- 退出

默认全局快捷键（可在设置中修改，冲突时提示）：

| 操作 | macOS | Windows |
| --- | --- | --- |
| 显示 / 隐藏全部便签 | ⌘⇧Space | Ctrl+Shift+Space |
| 新建便签 | ⌘⇧N | Ctrl+Shift+N |
| 打开管理面板 | ⌘⇧D | Ctrl+Shift+D |

“显示 / 隐藏全部”是临时切换：隐藏全部后再显示，只恢复原本可见的便签，单独隐藏的便签保持隐藏。

**管理面板**：一个普通窗口，含“便签”“历史”“设置”三页。应用单实例运行，再次启动应用即唤出管理面板，作为托盘不可用时的兜底入口。

### 3.6 设置

| 设置项 | 默认值 |
| --- | --- |
| 开机自启 | 开 |
| 换日时间 | 00:00 |
| 未完成事项自动顺延 | 开 |
| 外观 | 跟随系统（浅色 / 深色） |
| 便签透明度 | 100%（可调 70–100%） |
| 字号 | 中（小 13 / 中 14 / 大 16 px） |
| 全局快捷键 | 见 3.5 |
| 数据 | 导出备份 / 导入备份（单个 .json 文件）/ 打开数据目录 |

## 4. 视觉设计规范

整体风格是低饱和莫兰迪色 + 无边框圆角卡片 + 柔和投影：便签像一张安静的纸片浮在桌面上，而不是一个软件窗口。

### 4.1 便签配色

共 8 色。每色包含浅色模式背景、标题栏、深色模式背景和强调色（用于勾选框、置顶图标、输入光标）。

| 名称 | 浅色背景 | 浅色标题栏 | 深色背景 | 强调色 |
| --- | --- | --- | --- | --- |
| 雾蓝 | #E3EBF3 | #D5E0EC | #28323D | #6F8FB3 |
| 鼠尾草 | #E2EBDF | #D3E0CF | #29332A | #7A9A72 |
| 杏桃 | #F7E6D6 | #F0D7C0 | #3A2F26 | #B97A4E |
| 藕荷 | #ECE2EE | #E0D2E4 | #332B36 | #9A7CA6 |
| 奶油黄 | #F7F0D4 | #EFE4BC | #36332A | #A68B3C |
| 樱粉 | #F6E1E1 | #EED0D0 | #382B2D | #C07B80 |
| 青瓷 | #DCEDEA | #CBE2DE | #243432 | #5E9A92 |
| 暖灰 | #ECE9E4 | #E0DCD5 | #2E2C29 | #8C857B |

深色模式标题栏 = 深色背景叠加 6% 白色。所有颜色上的正文与次要文字对比度不低于 WCAG AA（4.5:1），强调色与白色对勾不低于 3:1。

### 4.2 文字颜色

| 用途 | 浅色模式 | 深色模式 |
| --- | --- | --- |
| 正文 | #2F3437 | #E6E4E1 |
| 次要（计数、标记） | #585E64 | #A6A39F |
| 已完成 | #A3A8AD，删除线 | #6E6B68，删除线 |
| 占位文字 | #9AA0A6 | #7A7774 |

不使用纯黑与纯白，文字始终偏暖灰，和低饱和背景更协调。

### 4.3 字体与排版

- 字体使用系统字体栈，不打包字体：`-apple-system, "SF Pro Text", "PingFang SC", "Segoe UI Variable", "Microsoft YaHei UI", sans-serif`。
- 标题 15px / 600 字重；事项 14px / 400；次要信息 12px。
- 行高 1.5，事项间距 6px，便签内边距 14px。

### 4.4 窗口形态

- 无系统边框，自绘标题栏，高 36px；按钮（置顶、色点、隐藏、更多）平时隐藏，悬停便签时淡入。
- 圆角 12px；描边 1px rgba(0,0,0,0.04)。
- 投影两层：0 1px 2px rgba(0,0,0,0.06) 与 0 8px 24px rgba(0,0,0,0.10)；深色模式投影加深到 0.30。
- 勾选框为 16px 圆形描边，完成后填充强调色并显示白色对勾。
- 未完成计数以小号次要色显示在标题右侧，如“3”。

### 4.5 动效

| 场景 | 效果 | 时长 |
| --- | --- | --- |
| 便签显示 | 透明度 0→1，缩放 0.96→1 | 180 ms |
| 便签隐藏 | 透明度 1→0，缩放 1→0.96 | 140 ms |
| 勾选完成 | 对勾描线 + 删除线从左划过，随后下沉 | 250 ms + 300 ms |
| 添加事项 | 新行从上方 4px 滑入并淡入 | 150 ms |
| 换日切换 | 内容淡出淡入 | 300 ms |

缓动统一用 ease-out；系统开启“减少动态效果”时只保留透明度变化。

## 5. 交互细节与边界情况

| 场景 | 处理方式 |
| --- | --- |
| 首次启动 | 自动创建一张“待办”便签（雾蓝），内含 3 条示例事项，示范添加、完成、删除 |
| 便签为空 | 显示占位文字“写下今天要做的事…”，输入行自动聚焦 |
| 事项超出便签高度 | 列表区域内部滚动，滚动条仅在滚动时出现 |
| 隐藏全部便签 | 托盘图标保留；首次隐藏全部时提示一次如何找回 |
| 删除最后一张便签 | 允许删除；托盘与管理面板提示“新建便签” |
| 外接显示器拔出 | 原本在该显示器上的便签移回主显示器，保持相对位置 |
| 跨天未关闭应用 | 到换日时间自动切换，正在编辑的输入先保存再切换 |
| 系统时间被调回过去 | 不回退业务日，等时间追上后再按正常规则换日 |
| 数据库损坏 | 启动时自动从最近一次自动备份恢复，并提示用户 |
| 快捷键被占用 | 设置页标红提示，保留旧值 |

**自动备份**：每天首次换日时把数据库复制一份到备份目录，保留最近 7 份。

## 6. 技术方案

采用 Tauri 2 + Svelte 5 + TypeScript + SQLite，纯本地存储：安装包约 5–10 MB，原生支持多窗口、无边框透明窗口、置顶、托盘、自启和全局快捷键。

### 6.1 技术栈

| 层 | 选型 | 用途 |
| --- | --- | --- |
| 应用框架 | Tauri 2（Rust） | 窗口、托盘、系统集成、数据读写 |
| 界面 | Svelte 5 + TypeScript + Vite | 便签、管理面板、历史页 |
| 样式 | 原生 CSS 变量 | 8 色主题与深浅色切换 |
| 拖拽排序 | svelte-dnd-action | 事项拖拽 |
| 数据库 | SQLite（rusqlite，WAL 模式） | 便签、事项、设置 |
| 官方插件 | autostart、global-shortcut、single-instance、window-state | 自启、快捷键、单实例、窗口状态 |
| 打包 | Tauri bundler | .dmg、.msi / .exe |

### 6.2 窗口结构

- 每张便签一个独立 WebView 窗口，加载同一页面，以便签 id 区分。
- 管理面板为单独窗口，按需创建，关闭即销毁。
- 所有数据读写都经 Rust 层，前端通过 Tauri command 调用；某个窗口修改后，Rust 层广播事件，其他窗口（如管理面板）同步刷新。

### 6.3 数据表

```sql
CREATE TABLE notes (
  id          TEXT PRIMARY KEY,   -- UUID
  title       TEXT NOT NULL,
  color       TEXT NOT NULL,      -- 色名，如 mist_blue
  x INTEGER, y INTEGER, width INTEGER, height INTEGER,
  visible     INTEGER NOT NULL DEFAULT 1,
  pinned      INTEGER NOT NULL DEFAULT 0,
  collapsed   INTEGER NOT NULL DEFAULT 0,
  sort_order  INTEGER NOT NULL,
  created_at  TEXT NOT NULL,
  deleted_at  TEXT                -- 软删除；非空表示已删除，历史仍可查
);

CREATE TABLE items (
  id           TEXT PRIMARY KEY,
  note_id      TEXT NOT NULL REFERENCES notes(id),
  content      TEXT NOT NULL,
  day          TEXT NOT NULL,     -- 业务日 YYYY-MM-DD，可为明天
  done         INTEGER NOT NULL DEFAULT 0,
  done_at      TEXT,
  carried_from TEXT,              -- 顺延来源事项 id
  carry_days   INTEGER NOT NULL DEFAULT 0,
  sort_order   INTEGER NOT NULL,
  created_at   TEXT NOT NULL
);
CREATE INDEX idx_items_day ON items(day, note_id);

CREATE TABLE settings (
  key   TEXT PRIMARY KEY,
  value TEXT NOT NULL
);
```

顺延时复制一条新事项到今天（`carried_from` 指向原事项），原事项保持未完成，因此历史天然准确。

### 6.4 平台差异

| 平台 | 注意点 | 处理 |
| --- | --- | --- |
| macOS | 便签与菜单栏应用不应出现在 Dock | ActivationPolicy 设为 Accessory；需 Apple 开发者账号签名与公证 |
| Windows | 便签不应出现在任务栏 | 便签窗口设置 skipTaskbar |
| Windows | 圆角与投影依赖系统版本 | Win11 使用系统圆角；Win10 用透明窗口自绘阴影 |
| Windows | 未签名安装包会触发 SmartScreen 警告 | 购买代码签名证书，或首版接受警告并在说明中注明 |

Linux 暂不支持。Tauri 本身支持 Linux，日后扩展时需重新评估透明窗口、Wayland 窗口定位与托盘兼容性。

**数据目录**：macOS `~/Library/Application Support/DeskNodes`，Windows `%APPDATA%\DeskNodes`。

## 7. 版本规划与验收标准

分三步发布：先做出好看、好用的单日便签，再补历史，最后打磨。

| 版本 | 范围 |
| --- | --- |
| V0.1 | 技术原型与内存实测（首项）；3.1、3.2 的 P0 功能；4 节全部视觉规范；托盘基础菜单；本地存储 |
| V0.2 | 换日与顺延；历史日历与日详情；管理面板；设置；全局快捷键；自动备份 |
| V1.0 | 全部 P1 功能；macOS 与 Windows 打包与签名；边界情况全部处理 |

**V1.0 验收标准**

- [ ] macOS 与 Windows 均可安装、自启，托盘或管理面板可找回所有隐藏便签
- [ ] 新建便签到输入第一条事项，纯键盘 2 步内完成
- [ ] 8 种颜色在浅色、深色模式下，正文与次要文字对比度均达到 4.5:1，强调色与白色对勾达到 3:1
- [ ] 冷启动到便签显示 < 1 秒；5 张便签同时显示时内存 < 200 MB
- [ ] 强制结束进程后重启，最后一次输入不丢失
- [ ] 跨越换日时间后，未完成事项正确顺延，历史显示正确完成率
- [ ] 重启后便签位置、大小、颜色、置顶状态与关闭前一致
