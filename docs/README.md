## 3. 整理基线与旧资料的主要差异

- **配色**：当前为七色。石墨已移除；旧 live 数据打开时转换为宣纸，封存历史读取时映射为宣纸；schema 仍为 7。
- **主入口**：当前为空数据也保留的六按钮独立工具条，不再使用旧的大矩形空状态窗口。
- **默认便签**：当前新建为自由便签，标准宽 288pt；旧原型 240pt 自由卡片不是新默认。底层 `NoteFrame` 的缺省宽仍为 240，正常 UI 新建由 `DesktopController` 传入 288。
- **工具条**：支持横／竖排列与吸边后自动收缩，取代“只有竖向且尺寸始终固定”的早期描述。
- **停靠**：旧停靠数据与显式停靠入口保留；自由便签靠边不会自动变成旧停靠便签。
- **全屏**：工具条与叠放提示可以进入全屏空间；实际层级为置顶的便签与停靠标签也可以。其他便签依靠独立边缘面板访问。
- **收起**：已具备全局汇聚收起，与早期“不做整体隐藏”的范围描述存在演进。它不是安全隐藏或隐私保护功能。
- **删除恢复**：除 5 秒撤销，还提供最近 30 天的最近删除列表；30 天是列表范围，当前没有物理清理任务。
- **状态验证**：旧 README 提到的 Linux 验证与“17 个原生测试”不能代表当前仓库的实际测试数量。以本套验收文档记录的当前运行结果为准。
