# DeskNodes 文档

本文档目录按主题指定唯一权威来源。更新前先核对当前代码；其他文档只链接到权威章节，不复制同一规则、数值或验证结果。

## 文档分工

- [功能与交互](REQUIREMENTS.md)：用户可见行为、业务规则和产品限制。
- [UI 规格](UI_SPEC.md)：颜色、字体、字号、几何、布局和视觉状态参数。
- [纸白轻笺设计说明](PAPER_WHITE_DESIGN.md)：选定设计方向、原因和本轮改动边界。
- [技术设计](TECHNICAL_DESIGN.md)：代码职责、数据契约和实现机制。
- [本机操作指南](native-build.md)：构建、签名、隔离运行及数据恢复步骤。
- [验收](ACCEPTANCE.md)：自动测试覆盖、待做的原生人工检查和最近一次验证结果。

## 更新规则

一个产品规则只在《功能与交互》定义；一个视觉参数只在《UI 规格》定义；一个实现机制只在《技术设计》定义；操作命令只在《本机操作指南》定义。设计说明记录理由，不复制最终参数。验收记录结果，不重新定义预期行为。文档入口和仓库首页只负责导航。
