# DeskNodes 改版补充：新建配色与全部置顶

本文件补充 `desknodes-desktop-redesign-prompt.md`（其 §4.1 的五个按钮因此变为六个），并取代 `docs/spec/macos-native/requirements.md` 中与之冲突的两点：色板包含石墨、只有边缘唤出面板可以出现在全屏应用上。规格原文受 N10 保护，保持不变。

## 1. 新建便签自动配色

### 1.1 色板
- 色板为 7 种：宣纸、柠黄、杏、樱、薰衣草、雾蓝、薄荷。石墨已移除，颜色菜单不再提供。
- 本机数据库中已是石墨的便签，打开时改为宣纸。不升级数据库版本，所以新旧备份可以互相导入。
- 历史快照受 SQL 触发器保护，不可修改：保留原值，读取时把石墨显示为宣纸。
- 导入含石墨的备份时，石墨按宣纸导入，不报错。

### 1.2 分配规则
- 新建时统计未删除便签的颜色，取用得最少的一种。
- 用量相同时，按色板顺序取最近新建便签颜色的下一种（循环）。
- 手动改过的颜色照常计入统计。不新增设置项或存储字段。

## 2. 全部置顶

### 2.1 工具条按钮
- 工具条在“收起”和“设置”之间新增一个切换按钮：
  - 关闭（默认）：图标 `pin`，文字“置顶”。各便签按自己的层级（桌面 / 普通 / 置顶）显示。
  - 打开：图标 `pin.slash`，文字“取消置顶”，按钮保持强调色底板。所有便签显示在其他应用上方，包括全屏应用。
- 开关不改写便签自己保存的层级，关闭后各便签恢复原层级。

### 2.2 状态
- 开关保存在本机偏好 `desk.topmost`，重启后保持，不进入备份，导入备份也不会改变它。
- 新建便签保存的层级仍是“桌面”。开关打开时，新便签和其他便签一样显示在最上层。
- 菜单栏“全部置顶 / 取消置顶”与工具条按钮是同一个开关，文字同步。
- 单张便签的层级菜单照常可用，改动在开关关闭后生效。

### 2.3 全屏应用
- 实际层级为置顶的便签及底部标签使用 `.fullScreenAuxiliary`，会出现在全屏应用上方；其余便签仍为 `.fullScreenNone`，不进入全屏空间。
- 工具条和收起时的堆叠提示始终使用 `.fullScreenAuxiliary`，全屏时也能点“取消置顶”。
- 删除提示、设置、历史等窗口不变。

## 3. 验收
- 连续新建 7 张便签，颜色各不相同；删除一张后再新建，补上缺的颜色。
- 已有石墨便签显示为宣纸；导入含石墨的旧备份成功。
- 默认状态下打开普通应用，便签被遮挡，与改版前一致。
- 点“置顶”后按钮变为“取消置顶”，所有便签浮在普通应用和全屏应用上方，且不抢当前应用的焦点。
- 点“取消置顶”后各便签恢复原层级，单独置顶的便签仍在最上层。
- 重启后开关状态保持，菜单栏与工具条一致。
