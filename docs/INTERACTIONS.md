# DeskNodes 交互文档

日期：2026-11-12。功能编号引用 [需求文档](REQUIREMENTS.md)，尺寸和页面引用 [UI 规范](UI_SPEC.md)。本文区分用户动作、状态变化和数据提交，不把浏览器原型当原生证据。

## 1. 三个独立状态域

### 1.1 整组便签

```text
expanded ──收起──> collapsing ──完成──> collapsed
   ↑                   │                  │
   └──完成── expanding <───展开─────────────┘
```

正在收起时可反向展开，正在展开时可再次收起；持久化只保存最后目标。每次操作增加 generation，旧完成回调失效。单张窗口位置按 NoteID 关联，动画中不逐帧写库。

### 1.2 工具条

```text
expanded → collapsing → round → expanding → expanded
```

只有已吸边才有自动收缩；形态和全局收起互不修改。拖动、按住、设置可见、动画和 VoiceOver 是额外条件，不应压缩成一个 collapsed 布尔值。

### 1.3 单张便签

每张独立保存展开／折叠、自由／停靠、桌面／普通／置顶，另有当前选择和键盘焦点。全局收起不能把每张 collapsed 都改为 true，全局置顶不能把每张 level 都改为 topmost。

## 2. 首次启动和空状态（FR-01）

1. 应用读库、恢复本机偏好、检查跨天后显示工具条。没有便签时不弹大空窗口、不填示例事项。
2. 首次登录启动询问在工具条启动后单独出现；“暂不启用”保存 declined，“启用”保存 requested 并向系统注册。系统拒绝或待批准要显示实际状态。
3. 关闭低频窗口后工具条继续存在；无便签状态下保留新建和设置入口。
4. 工具条离屏或不可见时，从菜单栏“显示工具条”恢复到当前显示器可见区域并展开。

重启恢复：整组便签按上次收起目标显示；工具条先恢复完整形态，再重新满足闲置计时条件，不直接恢复成圆形。

## 3. 新建、选中与编辑（FR-02／03）

新建触发 → 检查全局 marked text → 必要时展开便签 → 计算工具条旁位置 → 同一事务创建 Note 和空 Item → 差量刷新 → 选中新 NoteID → 激活应用、聚焦首行。

组词期间新建不执行；当前这一路径直接返回，不保证每次有额外错误提示。其他结构操作也需依据各入口的实际反馈，不笼统承诺统一弹窗。

点击便签窗口的标题、正文或空白区域建立选择。点击工具条不清选择，也不把工具条变成文字输入焦点。选择描边只是删除目标提示，不代表该卡片永远在其他应用之上。

标题为空时显示低干扰“标题”；编辑标题不强制提交到另一张卡片。正文输入交给 NSTextView，约 0.4 秒停顿后保存。普通刷新跳过活跃／组词编辑器的覆盖；非活跃副本不把旧文字反写库。

### 3.1 键盘与粘贴

- Return：组词中交给输入法；其余时候在当前项后添加并聚焦。
- Backspace：仅空字符串行触发空行删除；非空文字仍按原生删字。
- ↑／↓：无选区且位于首／末视觉行时切相邻事项；多行内部先按原生光标移动。
- ⌘Return：只切换当前聚焦事项完成状态，不影响其他行。
- ⌘Z：最新删除仍有效且尚未开始新的输入时优先删除撤销；否则走当前编辑器原生 undo。
- 多行粘贴：非空行拆成事项，移除常见列表标记；第一行原生插入当前选择，余行依次新增。单行粘贴按原生处理。

完成勾选更新同一 ItemID；不会立即移动到历史，也不自动改变事项排序。跨天才归档。多余空白行在失焦时清理，不弹删除提示。

## 4. 删除与恢复（FR-04）

### 4.1 删除整张

工具条删除要求：整组稳定展开、存在 selection、目标窗口当前可见且未 suppressed。否则按钮禁用。

触发 → 组词检查 → 提交已提交编辑 → 冻结原 Note 和全部子记录 → 软删除 live 便签和未归档 live 事项 → 清理选择／旧编辑器／保存任务 → 退场 → 更新工具条和 toast。

单张菜单删除使用相同业务动作。删除最后一张只剩工具条；不退出。普通单张删除不反复确认。

### 4.2 删除事项与五秒撤销

非空事项删除保存原记录到内存撤销栈；空白行清理是编辑整理，不创建撤销条目。toast 可以连续撤销有效删除，最新优先；五秒截止后不再提供该撤销，但数据库 tombstone 仍存在。

撤销恢复原身份、内容和原记录状态，不创建新便签替身。编辑开始后 ⌘Z 回到文字撤销，但 toast 在剩余时间内仍可点击。退出或成功导入后不能继续使用旧删除队列。

### 4.3 最近删除

菜单栏 → 最近删除，或历史顶部切换 → 按最近删除时间展示 → 点恢复。

恢复整张会先展开桌面、恢复与整张同次删除的子项并校正显示器；原先单独删掉的子项不随之恢复。单独事项回到原 live 便签末尾。恢复动作移除对应未过期内存删除条目，防止重复撤销冲突。历史快照维持原样。

列表时间窗为 30 天，当前没有永久删除按钮。历史中的“已删除”标记不是可以点击恢复的按钮。

## 5. 自由移动、折叠、停靠（FR-05）

自由便签拖动从标题非编辑区域开始，持续直接跟手，释放再保存；正文不转成窗口拖动区域。手动缩放保存 expanded frame 并关闭自动高度；折叠只投影成 32pt 标题条，顶边不漂移，展开还原 expanded frame。

便签菜单可切换颜色、层级、折叠和自动高度。顶部 pin 快捷切换取消时回到桌面层；如果需要普通层，用三层菜单明确设置。

自由便签放到边缘不会自动停靠。用户通过菜单显式“停靠到顶部／左侧／右侧”；原自由位置保存在 freeRestore。已有停靠便签可条内排序、拖出或通过菜单移出；停靠区保留约 48pt 宽的脱离判定带以减少误脱离。具体阈值与标签逻辑由 DockGeometry 管理，不能套用工具条 81pt 的吸边参数。

拔掉显示器后按现有屏幕校正；工具条和便签分别恢复，不能用移动工具条的动作带走全部便签。

## 6. 整理与容量（FR-06）

触发 → 检查组词／读取现有内容与屏幕 → 各屏按持久化顺序求 slot → 避让完整工具条目标 → 单事务保存 free placement → 保存本机分页关系、当前页归零 → 展示当前页并动画。

整理不是长期模式。之后手动拖动不会被后台拉回。原停靠便签参与后成为自由便签；单张折叠占位按折叠高度规划，但 expanded 高度保留。

当前页索引在多屏间共享，每屏显示 `min(current, pages−1)` 对应页；不把少页屏幕变成空屏。新建便签未登记在旧分页映射中，默认可见。切页不删除内容，非当前页窗口用 suppressed 隐藏，工具条删除跟随当前目标可见性。

## 7. 全局收起／展开（FR-07）

收起：安全提交 → 写入本机目标 collapsed → 停止显示停靠条／标签 → 记录休止 frame → 真实窗口向工具条旁提示汇聚并淡出 → orderOut／suppressed → 恢复窗口内部休止 frame 与 alpha，避免下一次动画从坏状态起步。

展开：写入本机目标 expanded → 隐藏叠放提示 → 只恢复当前整理页 → 按保存 frame 过渡并恢复交互 → 刷新停靠 → 更新按钮。

工具条圆形时用入口作为汇聚中心，角标只在便签已收起且 count>0 时显示。全局收起期间边缘面板仍是独立访问路径，所以“桌面没有卡片”不等于“其他入口不能显示内容”。

从收起状态新建，先展开再创建并聚焦；从收起状态整理，按新布局展开。没有便签时不出现空叠放提示，删除全部后清理全局收起目标。

## 8. 工具条磁吸、闲置与中断（FR-08）

### 8.1 释放与位置

展开态从手柄拖动，圆形从入口拖动。按下锁定本次手势并暂停形变；最大轴向位移达到 4pt 进入拖动，不再把抬起交给后出现的按钮。

释放位置优先选指针所在显示器；指针不在屏幕则使用最后有效屏。只考虑可容纳完整目标的屏幕外边，距可见外框不超过 81pt，选最近边；同距优先原边，否则按左、右、上、下。拖动中显示完整展开虚线预览，释放后落到其位置，边距 8pt。

圆形是手柄端锚点，不能为放下整根胶囊把圆形突然挪走；沿边方向保存归一化比例。平行于边时从手柄端展开，垂直时向屏内展开，必要时沿边平移但仍覆盖入口。自由位置保持中心并校正完整外框。

### 8.2 计时

稳定展开 + 已吸边 + 自动收缩开启 + 无动画／拖动／按住 + 设置不可见 + VoiceOver 关闭 + 指针在可见外壳之外，才计时。

操作或阻断取消旧任务；条件重新满足后等待完整 10／15／30 秒，不追补睡眠期间时长。仅鼠标在工具条上时每 0.5 秒复查；回调到期还要再次核对真实指针与状态。

### 8.3 圆形唤起和动画

圆形内停留 140ms、单击或辅助功能激活 → 完成展开。快速经过不触发；其他应用拖放按住时只等待，释放后仍在入口才展开。

仅由悬停唤起且没有点击／滚动的情况，移出后使用 1.5 秒宽限；一旦有效操作，回到用户设定完整时长。收缩中移入会连续反向；展开中移出先完成，不立刻来回闪动。

完整展开 260ms：外壳 0–180ms，入口在前 100ms 淡出，控件组 180–260ms 淡入。按钮只在稳定状态可执行。中断从当前显示 frame／透明度继续，不回起点；旧回调、计时器失效。

设置切方向保留业务状态；圆形中切方向保持圆形，下次展开用新布局。关闭自动收缩则立即恢复展开。新建快捷键不强制展开工具条，“显示工具条”会强制展开。

## 9. 置顶与边缘唤出（FR-09）

全局置顶开关只写 `desk.topmost` → WindowModes 计算有效层级 → 同步桌面、标签、工具条文字和菜单栏；关闭恢复单张保存值。开关打开时修改某张层级照常保存，关闭后生效。

桌面层点击编辑临时提升到普通层；应用失去活动状态后回落。工具条整理／收起／置顶不主动获取文字焦点；新建与编辑需要焦点。

边缘面板独立计时：侧边外缘 2pt 且 y 在 20%–80% 之间 → 0.25 秒 → 出现纵向全部便签；指针离开面板与该边、无组词和 attached sheet → 0.4 秒 → 提交编辑并收回。向下移动不是收回条件。

自动侧边为 Dock 在右则左，其余右；不能触发显示器接缝或重叠屏幕的同位置。外部拖动按住时不会新触发。面板显示时拓扑变化先等待组词结束，再关闭并要求新的停留。

## 10. 跨天、历史与备份（FR-10～13）

### 10.1 跨天

定时／启动／唤醒／时区时钟通知 → 计算当前业务日 → 若有组词延迟 → 提交拥有编辑权的文本 → 单事务封存上一已观察日、归档完成项、未完成项标记顺延到当前日、推进检查点 → 刷新 → 写滚动 SQLite 备份。

历史日历读取不触发 capture。睡眠跨多日不会凭空出现连续“每天记录”。当前日仍未结束时没有快照是正常状态。

### 10.2 导出

设置 → 数据 → 导出 → 检查组词并提交 → 取完整业务快照并编码 → 保存面板 → 选择路径 → 原子写 JSON。取消保存面板不写文件；已提交的文字仍是正常业务编辑。

### 10.3 导入

设置 → 数据 → 导入 → 组词检查 → 选择单个 JSON → 格式／引用／staging 校验 → “替换全部本机数据？” → 取消或明确替换。

确认后先试候选快捷键，成功才原子替库；失败保留旧库与旧快捷键。成功后使旧编辑器、保存任务、撤销、停靠与边缘展示失效并重建，避免旧任务覆盖新内容。

导入会改变业务便签布局；不改变工具条、全局收起／置顶和整理页的本机展示偏好，也不会根据登录意愿注册 OS 登录项。导入完成不立即跨天，后续 timer 可能推进旧检查点。

## 11. 异常反馈约定

- 库打不开等启动失败：明确错误框，不继续假装空库正常启动。
- 后台保存／定时／边缘轮询错误：日志和短暂非激活通知；不打断输入做连环模态框。
- 设置保存／热键冲突：设置内错误文字，失败后 reload 有效值；候选注册失败保留旧绑定。
- 导入无效或取消：保留旧数据、窗口和绑定，不先清库。
- 屏幕丢失：优先保证入口可见，不让旧动画把窗口留在离线屏幕。
- 历史／最近删除读取失败：显示失败与重试，不用“没有数据”掩盖读取错误。
