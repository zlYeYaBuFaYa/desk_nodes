# F9 — History statistics

The history calendar has a quiet three-column strip for the current business week's completion rate, the displayed month's completion rate, and consecutive achieved days. Rates aggregate item counts (not an average of daily percentages), include deleted notes' historical items, and return zero for an empty denominator. Rust returns fractional rates; the UI rounds only for display. Week boundaries are Monday–Sunday, including weeks crossing month/year boundaries. All statistics and calendar aggregates exclude dates after the persisted business date.

A day achieves when it has at least one item and every item is done. If today achieves, it extends the streak; otherwise yesterday anchors the streak so today's unfinished work does not erase yesterday's progress. Walking backward stops at the first empty or incomplete day. Calendar days include weekends. This rule is documented on the helper and in the streak tooltip. The streak and week always refer to the current business date, even while browsing an older month.

`history_stats` accepts an optional month; omission uses the current business month. Calculation is pure and separately tested. The command uses `day::current`, preserving rollover, fake-clock and backward-clock behavior. Month navigation requests calendar and stats together and discards results for a different month. Existing note/item/day events and historical toggles refresh the strip.
