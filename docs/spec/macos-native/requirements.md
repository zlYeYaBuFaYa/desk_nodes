# DeskNodes 需求文档

2026-11-07

## 概述

DeskNodes 是一款 macOS 原生桌面便签，用来记录每天的待办事项。核心诉求是轻量、美观、交互优雅。

- 平台：只做 macOS，最低支持 macOS 14。
- 使用范围：暂时只给自己用，不分发。不需要付费开发者账号和公证，Xcode 本地签名运行，不开沙盒。
- 界面语言：只做中文。
- 性能：不设强制指标，以轻量为目标，优先选择内存占用低的实现方式。

## 技术方案

语言是 Swift，界面采用 AppKit 为骨架、SwiftUI 做低频界面的混合方式。常驻部分用 AppKit 保证低内存，偶尔打开的窗口用 SwiftUI 提高开发效率。

| 模块 | 框架 | 原因 |
| --- | --- | --- |
| 应用入口、菜单栏图标 | AppKit | 不显示 Dock 图标，需要精细控制 |
| 便签窗口（NSPanel） | AppKit | 层级、所有 Space、停靠都依赖它 |
| 待办事项编辑 | AppKit（NSTextView） | 中文输入法最稳定 |
| 动画 | Core Animation | 原生、性能好 |
| 全局快捷键、边缘唤出 | AppKit | 只有它能实现 |
| 设置窗口 | SwiftUI | 低频使用，开发快 |
| 历史记录窗口 | SwiftUI | 日历和统计视图写起来快 |

- 数据存储：系统自带的 SQLite，只存在本机，不引入第三方库。
- 全局快捷键：Carbon 的 RegisterEventHotKey，不需要辅助功能权限。

## 便签与事项

每张便签是一个长期存在的待办清单，可以新建和删除。不支持单独隐藏某张便签。

- 标题：可选。没有标题时，折叠状态显示第一条事项。
- 事项：可新增、编辑、勾选完成、删除；同一张便签内可以拖动排序，不能拖到别的便签。
- 已完成的事项：文字变灰并加删除线，跨天时移入历史。
- 背景色：预设 8 种，右键菜单切换，自动适配深色模式（见视觉规范）。
- 尺寸：可调整大小，也可以折叠成只显示标题栏。
- 删除保护：删除后底部提示「撤销」5 秒，同时支持 ⌘Z。
- 第一版不做：截止时间、提醒、Markdown。

## 每日与历史

每天凌晨 4 点跨天：已完成的事项移入历史，未完成的事项留在便签上自动顺延。

- 跨天时间点默认 4:00，可在设置里修改。
- 电脑睡眠跨过跨天时间点，唤醒后自动补做跨天处理。
- 历史永久保存，记录每天结束时的状态快照。
- 历史窗口：日历视图，点某一天显示当天各便签的事项和完成情况。
- 删除的事项和便签在历史中保留，标注「已删除」。
- 导出与导入：JSON 格式的完整备份。

## 层级、停靠与布局

便签默认在最低的桌面层，会被其他窗口盖住；停靠条和自由便签可以并存。

| 层级 | 位置 | 别的应用全屏时 |
| --- | --- | --- |
| 桌面层（默认） | 所有窗口之下、桌面图标之上 | 不显示，靠边缘唤出 |
| 普通 | 和普通窗口一样参与前后排序 | 不显示，靠边缘唤出 |
| 置顶 | 浮在所有窗口之上 | 不显示，靠边缘唤出 |

- 层级可以逐张设置，也可以用「全部置顶 / 全部恢复」总开关。
- 桌面层便签被部分遮挡时，点击它会临时提到最前面，点别处后回到原层级。
- 停靠条：停在屏幕顶部或侧边，默认在主屏幕，可在设置里修改；条内可拖动排序；便签过多时折叠成标签。
- 自由便签：可以拖到屏幕任意位置。拖出停靠条即变成自由便签，拖近屏幕边缘会吸附回停靠条。
- 停靠位置使用系统的可用区域，自动避开菜单栏和 Dock。
- 拔掉外接显示器后，原来在那块屏幕上的便签自动移回主屏幕。

## 边缘唤出

便签被全屏应用或最大化窗口挡住时，鼠标移到屏幕侧边，会滑出一个面板，所有便签纵向排列在里面，可以滚动。

- 唤出边：自动选择没有 Dock 的那条侧边（Dock 在底部或左侧时用右侧，Dock 在右侧时用左侧），可在设置里修改。不用顶部，因为全屏时顶部会弹出菜单栏和工具栏。
- 触发区：只取边缘中间约 60% 的部分，避开触发角。
- 多显示器：只在外侧的边生效，屏幕相接的边不触发。
- 防误触：鼠标停留约 0.25 秒后弹出；离开面板区域约 0.4 秒后收起。不以「鼠标下移」作为收起条件，避免去勾选事项时面板消失。
- 实现上不判断便签是否被遮挡，唤出功能始终可用。
- 便签窗口需要加入所有 Space，才能在全屏应用里被唤出。

## 快捷键与菜单栏

全局快捷键只有一个：⌃⌥N 新建便签，可在设置里自定义。快捷键被其他软件占用时给出提示。

- 避开的组合：⌥⌘H（系统「隐藏其他」）、⌃⌥空格（切换输入法）、⌥⌘D（显示/隐藏 Dock）。
- 便签内快捷键：回车新增事项，在空事项上退格删除该事项，⌘Z 撤销。
- 菜单栏图标：常驻，菜单包含新建便签、全部置顶/全部恢复、历史记录、设置、退出。
- 开机自启：首次启动时询问。

## 视觉规范

整体走柔和低饱和路线，背景用纯色而不是毛玻璃，保证在任何壁纸上文字都清晰。

**配色**（默认「宣纸」）

| 名称 | 浅色模式 | 深色模式 |
| --- | --- | --- |
| 宣纸 | #F6F1E7 | #2B2822 |
| 柠黄 | #FAF0C8 | #35301A |
| 杏 | #FBE7D6 | #3A2A20 |
| 樱 | #F7E1E4 | #3A2328 |
| 薰衣草 | #ECE6F5 | #2A2536 |
| 雾蓝 | #E3ECF5 | #1F2A36 |
| 薄荷 | #E2F0E8 | #1E2E26 |
| 石墨 | #E8E8EA | #2A2A2D |

文字浅色模式用接近黑的深灰，深色模式用接近白的浅灰。每张便签有一圈极细描边和很淡的阴影。

**字体**：系统 SF Pro 加苹方，数字用等宽数字。标题 13pt 中粗体，事项 13pt 常规字体，行高约 26pt。

**尺寸**

| 项目 | 数值 |
| --- | --- |
| 自由便签默认宽度 | 240pt，高度随内容增长，480pt 后内部滚动 |
| 自由便签可调范围 | 200×120pt 至 400×600pt |
| 折叠后高度 | 32pt |
| 顶部停靠 | 每张 220×260pt；屏幕较矮时高度降到 200pt |
| 侧边停靠 | 宽 240pt，高度随内容 |
| 便签间距 / 离屏幕边缘 | 12pt / 8pt |
| 圆角 / 内边距 | 12pt / 14pt |

**动效**：使用 Core Animation 短弹簧动画，时长 0.25–0.35 秒，用于新建、删除、吸附、排序、折叠、边缘唤出；遵循系统「减弱动态效果」设置。

## 不做的功能与待确认项

第一版明确不做以下功能：Windows 版本、Markdown、双击空白处显示/隐藏、整体隐藏/显示（含 Touch ID 验证、闲置自动隐藏、屏幕共享时隐藏）、单张便签隐藏、截止时间与提醒、iCloud 同步、强制性能指标。

以下几项上一轮评审时未明确回复，暂按推荐方案写入本文档，可随时修改：

- [ ] 跨天时已完成事项移入历史，未完成事项顺延
- [ ] 跨天时间点默认凌晨 4 点
- [ ] 边缘唤出为纵向面板，包含全部便签
- [ ] 点击被遮挡的桌面层便签时临时提到最前
- [ ] 事项只能在同一便签内拖动排序
- [ ] 便签标题可选
- [ ] 历史保留已删除内容，标注「已删除」
- [ ] JSON 备份支持导出和导入
