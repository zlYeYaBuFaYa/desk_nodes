# DeskNodes Windows 交互设计

交互的业务结果以 [FR-01～15](REQUIREMENTS.md) 为准，数值集中在 [UI 规格](UI_SPEC.md)，窗口机制见 [技术设计](TECHNICAL_DESIGN.md)。这里定义事件分派与 Windows 使用习惯；全部尚待实施。

## 指针、触控板与触摸

左键点击正文进入原生文字编辑，标题可编辑文字和非编辑拖动区必须有明确命中边界；手柄显示移动指针，窗口边显示标准缩放指针。行尾手柄只在同便签内排序，正文拖动保留文字选区。右键或更多按钮打开便签菜单，键盘 Shift+F10／菜单键提供同一入口。颜色、层级和停靠项目有勾选；删除不放到工具条。

工具条拖动与点击采用按下→捕获→阈值→释放流程，跨过需求阈值后只落位、不执行松手下方按钮。捕获丢失、屏幕断开、Esc 或系统取消时回到最后安全框，释放捕获。圆形可以拖动，悬停唤起后按钮必须等稳定状态才响应。外部文件／文字拖放经过圆形不展开，也不误认为新建事项。

触控板单指指针和双指滚动沿系统事件处理，不接管三／四指系统桌面手势；不增加捏合调字号手势。触屏点按等价点击，拖手柄等价移动，长按可走系统右键菜单；不依赖悬停才能删除／排序，提供菜单及键盘替代。多点触控优化不是当前验收承诺，单点可达性需 Windows 真机验证。

## 多窗口与焦点

普通选择表示操作目标，文字焦点表示编辑所有者，二者不互相推导。工具条常规动作以非激活方式调用当前选择，不抢正文焦点；新建、设置、历史、系统文件对话框是明确激活边界。菜单关闭回到原编辑器和选区；无法恢复时保留内容，不强行把光标移到末尾。

组词期间结构命令先由统一提交屏障拒绝／延迟；不能靠隐藏窗口来强迫 IME 提交。Return、Esc 和候选数字优先属于输入法；打开录制、模态警告或文件对话框后，Esc 优先属于当前上下文，再是多选，最后浮起。失焦要分辨自家窗口、候选窗和其他应用，不能在用户选字时误放回便签。

切到其他应用结束多选及浮起，恢复保存层级；切自家设置／历史不当作切应用，但模态流程拥有键盘。系统拒绝前台激活时保持可见反馈，用户可点便签继续，不通过重复激活争焦点。退出失败保留窗口和缓冲；关机强制结束不承诺可阻止。

## 托盘与恢复入口

托盘左键显示工具条，右键给出 FR-01 菜单；键盘通过 Windows 通知区域导航访问同菜单。显示工具条校正屏幕并展开其自身，不改变全局收起目标。托盘图标可能位于溢出区，应用不可强制固定；工具条、托盘和全局快捷键互为恢复入口。辅助窗口关叉只关闭该窗口，退出只走显式动作。

便签／工具条不逐张出现任务栏按钮；设置／历史为普通窗口。Explorer 重启后重建托盘入口，显示器丢失后将工具条校正到可见工作区。Win+D／显示桌面由系统处理，不劫持、不保证便签仍显示。虚拟桌面切换不自动移动窗口或切回原桌面，当前找不到便签时给出原桌面查找说明；替代方案见可行性。

## 停靠、整理与收起

停靠通过单张菜单明确发生；靠近边缘仅有工具条磁吸，不让自由便签意外吸边。停靠条内拖动预览排序，越过保留带才脱离并恢复自由几何；未越过则回条内。溢出标签提升显示对应便签，隐藏溢出不参与框选。分页、停靠和工具条不是 Windows 任务栏 AppBar，不挤压其他应用工作区。

整理按一次动作执行，结束手动调整不被吸回；当前页隐藏原因参与统一可见性计算。全局收起操作真实窗口汇聚后隐藏，展开恢复原位置而非新建影子编辑器。工具条圆形态与全局收起互相独立，点击数量叠放提示和点击收起／展开采用同一命令。快速反向用最新请求和 generation 使旧回调无效。

边缘唤起只在圆形实际可命中的区域有效；不铺一圈隐形全局热区。全屏遮住入口时使用全局热键／退出全屏后托盘；不承诺在独占全屏、UAC 或锁屏上显示。减少动画时同样可反向，直接到最新目标，不能留下透明遮挡窗。

## 快捷键映射

| 上下文 | Windows | 与 Mac 的关系／保护 |
|---|---|---|
| 应用内新建 | Ctrl+N | 替代 ⌘N，组词拒绝 |
| 全局新建／浮起 | Ctrl+Alt+N／Ctrl+Alt+F | 可配置；AltGr 风险，不用 Windows 键 |
| 事项插入 | Return | IME 确认优先 |
| 事项空行删除 | Backspace | 普通 Delete 保留原生含义 |
| 完成／划掉 | Ctrl+Return／Ctrl+Shift+X | 不在组合输入中抢键 |
| 跨事项 | ↑／↓ | 首末视觉行、无选区才跨 |
| 撤销 | Ctrl+Z | 删除有效且未新输入优先结构，否则文字 |
| 字号 | Ctrl++／Ctrl+=、Ctrl+-、Ctrl+0 | 组词拒绝，端点不变 |
| 多选入口／追加框 | Ctrl+单击／Ctrl+拖动 | 替代 ⌘，不拦截系统全局 Ctrl |
| 模式内全选／删除 | Ctrl+A、Backspace／Delete | 仅模式内批量，普通编辑不批删 |
| 完成模式／放回浮起 | Esc | IME、录制、对话框先处理 |
| 上下文菜单 | Shift+F10／菜单键 | Windows 原生可达入口 |

全局键按 VK 和修饰注册，不声明物理 ANSI 布局一致；录制展示实际组合，Esc 取消，先试候选再换旧绑定。Win 系统键组合、Alt+Tab、Ctrl+Alt+Delete 等系统命令不录入；当前模型至少含 Ctrl，避免单键或 Alt 单独抢菜单。录制中不执行应用快捷命令。

## 多选覆盖与辅助功能

Ctrl 从便签按下即能进入并继续同手势框选；模式内拦截便签正文按下，防止放光标。跨屏框选统一坐标，显示覆盖层按各屏 DPI 裁切；松手按相交集合确定，不按鼠标最后所在屏丢弃其他屏。空白清选择不退出，切应用立即移除覆盖层并归还桌面命中。

不在普通模式截取 Explorer 桌面空白拖动。覆盖层只存在于模式会话，操作条和真实便签在其上；Narrator 可以读选择计数、勾选状态和删除禁用原因。所有动作可从菜单／键盘完成，用户可保持工具条展开；屏幕阅读器检测不是无条件可靠保证。未来重点验证输入法候选、自动收缩、多选覆盖、浮起、停靠和不同 DPI 同时发生的组合。
